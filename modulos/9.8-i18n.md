## El sistema de i18n de Magento

🔄 **Laravel**: `trans('messages.welcome')` — claves de traducción en archivos PHP/JSON organizados por clave.

Magento usa un sistema diferente: **la cadena original en inglés ES la clave**:

```php
// Laravel: clave → traducción
__('messages.add_to_cart')  // → "Add to Cart"

// Magento: string original → traducción
__('Add to Cart')  // → "Agregar al carrito" (en es_MX)
```

Ventaja: el código es legible sin consultar el archivo de traducciones.
Desventaja: si cambias el string original en inglés, pierdes la traducción.

---

## El helper `__()`

```php
// En templates .phtml:
<?= __('Add to Cart') ?>
<?= $block->escapeHtml(__('Hello, %1', $name)) ?>
<?= __('%1 items in your cart', $count) ?>

// En clases PHP:
use Magento\Framework\Phrase;
$phrase = __('Product saved successfully.');   // → Phrase object
$string = (string) $phrase;                    // → string traducido

// En el constructor de excepciones:
throw new LocalizedException(__('The product could not be saved.'));

// Plural manual:
$label = $count === 1 ? __('1 product') : __('%1 products', $count);
```

## Archivo de traducción: estructura

```
app/code/MiVendor/Blog/
└── i18n/
    ├── es_MX.csv   ← Español México
    ├── es_ES.csv   ← Español España
    └── fr_FR.csv   ← Francés
```

**Formato del CSV** — dos columnas: original, traducción:

```csv
"Add to Cart","Agregar al carrito"
"Remove","Eliminar"
"Hello, %1","Hola, %1"
"%1 items in your cart","%1 artículos en tu carrito"
"The post was saved successfully.","El post se guardó correctamente."
"This post no longer exists.","Este post ya no existe."
"Could not save the post: %1","No se pudo guardar el post: %1"
"Read more","Leer más"
"Recent Posts","Posts recientes"
"By %1","Por %1"
```

**Reglas del CSV**:
- Siempre con comillas (obligatorio si el string tiene comas)
- Los placeholders `%1`, `%2` deben estar en la traducción
- Una línea por traducción
- Sin BOM (UTF-8 sin BOM)

## Traducciones por tema

Los temas también pueden tener traducciones — con mayor prioridad que el módulo:

```
app/design/frontend/MiVendor/MiTema/
└── i18n/
    └── es_MX.csv   ← sobreescribe las del módulo para este tema
```

**Prioridad de traducciones** (mayor gana):
```
1. Traducciones del módulo (i18n/ en el módulo)
2. Traducciones de dependencias del tema
3. Traducciones del tema activo
4. Traducciones en la DB (Stores > Configuration > General > Locale)
```

## Traducciones en JavaScript

Para JS tienes dos opciones:

### Opción 1: `mage/translate` (RequireJS)

```javascript
// En un archivo .js de tu módulo
define(['mage/translate'], function ($t) {
    'use strict';

    return {
        getMessage: function () {
            return $t('Add to Cart');     // usa el mismo CSV
        }
    };
});
```

### Opción 2: `$.mage.__()` (jQuery)

```javascript
// En inline scripts o archivos jQuery
var message = $.mage.__('Item added to cart');
```

### Hacer strings JS traducibles — `js-translation.json`

Para que las traducciones del CSV lleguen al JS, debes declarar los strings en el layout:

```xml
<!-- En el layout XML: -->
<head>
    <script type="text/x-magento-init">
    {
        "*": {
            "Magento_Ui/js/core/app": {}
        }
    }
    </script>
</head>
```

O más directamente, en `view/frontend/requirejs-config.js`:

```javascript
var config = {
    config: {
        mixins: {
            'Magento_Catalog/js/catalog-add-to-cart': {
                'MiVendor_Blog/js/catalog-add-to-cart-mixin': true
            }
        }
    }
};
```

## Traducciones de la DB (Inline Translations)

Magento permite editar traducciones desde el admin sin tocar archivos:

```
Stores > Configuration > Advanced > Developer > Translate Inline
```

Activa un modo donde puedes hacer clic en cualquier texto de la tienda y editarlo. Se guarda en la tabla `translation`.

**Prioridad**: DB > Tema > Módulo. Útil para que el merchant personalice textos sin código.

## Pluralización avanzada

Magento no tiene pluralización automática. El patrón común:

```php
// Simple (inglés):
$label = $count === 1 ? __('1 post') : __('%1 posts', $count);

// Para idiomas con más formas plurales (polaco, árabe, etc.)
// usar ICU Message Format con Magento\Framework\Phrase\Renderer\Composite:
// (raro en proyectos típicos — la mayoría usa el patrón simple)
```

---

## Traducir en el admin

```php
// En classes del adminhtml, el locale puede ser diferente al frontend
// Usa el mismo __() — Magento selecciona el locale correcto por área
$label = __('Save Post');  // → se traduce al locale del admin (configurado en el usuario admin)
```

## Buenas prácticas

```
✅ Siempre wrappear strings visibles con __()
✅ Usar placeholders %1, %2 en vez de concatenar
✅ El CSV va en i18n/ del módulo (no en view/)
✅ Una traducción por módulo — no un CSV gigante
✅ Incluir TODOS los strings en inglés en el CSV (para documentación)

❌ Concatenar strings con __(): __('Hello ') . $name (roto en algunos idiomas)
   ✅ __('Hello, %1', $name)
❌ Números hardcodeados fuera de __(): echo "5 productos"
   ✅ echo __('%1 productos', 5)
❌ Traducir en el backend y olvidar el JS
```

## Resumen

```
Sistema: string original en inglés = clave

Helper: __('String original')
        __('String con %1 placeholder', $variable)

Archivo: i18n/{locale}.csv en el módulo o tema
Formato CSV:
  "Original string","Traducción"
  "With %1 placeholder","Con %1 marcador"

Deploy: php bin/magento setup:static-content:deploy es_MX -f

Prioridad: DB > Tema > Módulo
```

### Ejercicio 2 — Traducción en JavaScript

Escribe un archivo `view/frontend/web/js/blog-utils.js` que use `mage/translate` para un mensaje de confirmación al eliminar un post desde el frontend.

<details>
<summary>Ver solución</summary>

```javascript
// view/frontend/web/js/blog-utils.js
define([
    'jquery',
    'mage/translate',
    'Magento_Ui/js/modal/confirm'
], function ($, $t, confirm) {
    'use strict';

    return {
        /**
         * Mostrar confirmación antes de eliminar
         */
        confirmDelete: function (postId, deleteUrl) {
            confirm({
                title: $t('Delete Post'),
                content: $t('Are you sure you want to delete this post? This action cannot be undone.'),
                actions: {
                    confirm: function () {
                        $.post(deleteUrl, {
                            id: postId,
                            form_key: window.FORM_KEY
                        }).done(function (response) {
                            if (response.success) {
                                window.location.reload();
                            } else {
                                alert($t('Could not delete the post. Please try again.'));
                            }
                        });
                    }
                }
            });
        }
    };
});
```

```csv
<!-- Agregar al i18n/es_MX.csv: -->
"Delete Post","Eliminar post"
"Are you sure you want to delete this post? This action cannot be undone.","¿Estás seguro de que deseas eliminar este post? Esta acción no se puede deshacer."
"Could not delete the post. Please try again.","No se pudo eliminar el post. Por favor intenta de nuevo."
```

```bash
php bin/magento setup:static-content:deploy es_MX -f
```

</details>
