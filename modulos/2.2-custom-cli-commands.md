## Por qué crear comandos CLI

En proyectos reales necesitarás tareas como:

- Sincronizar productos desde un ERP
- Recalcular precios de forma masiva
- Limpiar datos obsoletos
- Enviar reportes por email
- Importar clientes desde un CSV

🔄 **Laravel**: Es exactamente igual que `php artisan make:command`. La diferencia es que en Magento el comando se registra en `di.xml` en lugar de en `Kernel.php`.

---

## Estructura de un comando

```
app/code/MiVendor/MiModulo/
├── Console/
│   └── Command/
│       └── SincronizarProductosCommand.php   ← Tu comando
└── etc/
    └── di.xml                                ← Registro del comando
```

## Paso 1 — Crear la clase del comando

```php
// app/code/MiVendor/MiModulo/Console/Command/SincronizarProductosCommand.php
namespace MiVendor\MiModulo\Console\Command;

use Symfony\Component\Console\Command\Command;
use Symfony\Component\Console\Input\InputInterface;
use Symfony\Component\Console\Input\InputArgument;
use Symfony\Component\Console\Input\InputOption;
use Symfony\Component\Console\Output\OutputInterface;
use Magento\Framework\App\State;
use Magento\Framework\App\Area;

class SincronizarProductosCommand extends Command
{
    // El nombre que usarás en la terminal: bin/magento mimodulo:productos:sincronizar
    protected static $defaultName = 'mimodulo:productos:sincronizar';

    public function __construct(
        private readonly State $appState,
        // Inyecta aquí los servicios que necesites
        string $name = null
    ) {
        parent::__construct($name);
    }

    protected function configure(): void
    {
        $this
            ->setDescription('Sincroniza productos desde el ERP externo')
            ->setHelp('Este comando obtiene productos del ERP y los actualiza en Magento.')
            // Argumentos obligatorios
            ->addArgument(
                'tipo',
                InputArgument::REQUIRED,
                'Tipo de sincronización: full | delta'
            )
            // Opciones opcionales (con --)
            ->addOption(
                'limit',
                'l',                           // alias corto: -l
                InputOption::VALUE_OPTIONAL,
                'Límite de productos a procesar',
                100                            // valor por defecto
            )
            ->addOption(
                'dry-run',
                null,
                InputOption::VALUE_NONE,       // flag booleano, sin valor
                'Simular sin guardar cambios'
            );
    }

    protected function execute(InputInterface $input, OutputInterface $output): int
    {
        // 1. Setear el área — OBLIGATORIO en comandos CLI
        try {
            $this->appState->setAreaCode(Area::AREA_FRONTEND);
        } catch (\Magento\Framework\Exception\LocalizedException $e) {
            // Ya estaba seteada, ignorar
        }

        // 2. Leer argumentos y opciones
        $tipo   = $input->getArgument('tipo');
        $limit  = (int) $input->getOption('limit');
        $dryRun = (bool) $input->getOption('dry-run');

        // 3. Validar argumentos
        if (!in_array($tipo, ['full', 'delta'])) {
            $output->writeln('<error>El tipo debe ser "full" o "delta"</error>');
            return Command::FAILURE;
        }

        // 4. Output con formato
        $output->writeln('<info>Iniciando sincronización...</info>');
        $output->writeln(sprintf(
            '<comment>Tipo: %s | Límite: %d | Dry-run: %s</comment>',
            $tipo,
            $limit,
            $dryRun ? 'sí' : 'no'
        ));

        // 5. Tu lógica aquí
        try {
            $procesados = $this->sincronizar($tipo, $limit, $dryRun, $output);

            $output->writeln(sprintf(
                '<info>✓ Sincronización completada: %d productos procesados</info>',
                $procesados
            ));

            return Command::SUCCESS;

        } catch (\Exception $e) {
            $output->writeln('<error>Error: ' . $e->getMessage() . '</error>');
            return Command::FAILURE;
        }
    }

    private function sincronizar(
        string $tipo,
        int $limit,
        bool $dryRun,
        OutputInterface $output
    ): int {
        $procesados = 0;

        // Simular procesamiento con progress
        for ($i = 1; $i <= $limit; $i++) {
            // Si es dry-run, no guardes nada
            if (!$dryRun) {
                // $this->miServicio->procesarProducto($i);
            }

            $output->writeln("  Procesando producto {$i}/{$limit}", OutputInterface::VERBOSITY_VERBOSE);
            $procesados++;
        }

        return $procesados;
    }
}
```

## Paso 2 — Registrar el comando en di.xml

```xml
<!-- app/code/MiVendor/MiModulo/etc/di.xml -->
<config xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
        xsi:noNamespaceSchemaLocation="urn:magento:framework:ObjectManager/etc/config.xsd">

    <type name="Magento\Framework\Console\CommandList">
        <arguments>
            <argument name="commands" xsi:type="array">
                <item name="mimodulo_sincronizar_productos"
                      xsi:type="object">
                    MiVendor\MiModulo\Console\Command\SincronizarProductosCommand
                </item>
            </argument>
        </arguments>
    </type>

</config>
```

## Paso 3 — Registrar y usar

```bash
# Habilitar el módulo y actualizar el registro
php bin/magento module:enable MiVendor_MiModulo
php bin/magento setup:upgrade
php bin/magento cache:flush

# Verificar que aparece en la lista
php bin/magento list | grep mimodulo
# mimodulo:productos:sincronizar  Sincroniza productos desde el ERP externo

# Ver la ayuda del comando
php bin/magento mimodulo:productos:sincronizar --help

# Correrlo con argumento obligatorio
php bin/magento mimodulo:productos:sincronizar full

# Con opciones
php bin/magento mimodulo:productos:sincronizar delta --limit=50

# Dry-run (flag booleano)
php bin/magento mimodulo:productos:sincronizar full --dry-run

# Verbose — muestra los writeln con VERBOSITY_VERBOSE
php bin/magento mimodulo:productos:sincronizar full -v
```

## Output con estilos y Progress Bar

```php
protected function execute(InputInterface $input, OutputInterface $output): int
{
    $this->appState->setAreaCode(Area::AREA_FRONTEND);

    // ── Estilos de output ──────────────────────────────────────────
    $output->writeln('<info>Texto en verde</info>');
    $output->writeln('<comment>Texto en amarillo</comment>');
    $output->writeln('<error>Texto en rojo con fondo</error>');
    $output->writeln('<question>Texto en cyan</question>');
    $output->writeln('Texto normal');

    // ── Niveles de verbosidad ──────────────────────────────────────
    // Normal (sin flags):
    $output->writeln('Siempre visible');

    // Solo con -v:
    $output->writeln('Detalle', OutputInterface::VERBOSITY_VERBOSE);

    // Solo con -vv:
    $output->writeln('Muy detallado', OutputInterface::VERBOSITY_VERY_VERBOSE);

    // Solo con -vvv:
    $output->writeln('Debug', OutputInterface::VERBOSITY_DEBUG);

    // ── Progress Bar ───────────────────────────────────────────────
    $items = range(1, 100);

    $progressBar = new \Symfony\Component\Console\Helper\ProgressBar($output, count($items));
    $progressBar->setFormat(' %current%/%max% [%bar%] %percent:3s%% %elapsed:6s%/%estimated:-6s%');
    $progressBar->start();

    foreach ($items as $item) {
        // procesar item...
        $progressBar->advance();
    }

    $progressBar->finish();
    $output->writeln(''); // salto de línea después del progress bar

    return Command::SUCCESS;
}
```

## Preguntar al usuario durante la ejecución

```php
use Symfony\Component\Console\Question\ConfirmationQuestion;
use Symfony\Component\Console\Question\Question;
use Symfony\Component\Console\Question\ChoiceQuestion;

protected function execute(InputInterface $input, OutputInterface $output): int
{
    $this->appState->setAreaCode(Area::AREA_ADMINHTML);
    $helper = $this->getHelper('question');

    // ── Confirmación Sí/No ─────────────────────────────────────────
    $question = new ConfirmationQuestion(
        '¿Estás seguro de que quieres borrar 5000 productos? [y/N] ',
        false   // valor por defecto: No
    );

    if (!$helper->ask($input, $output, $question)) {
        $output->writeln('<comment>Operación cancelada.</comment>');
        return Command::SUCCESS;
    }

    // ── Input de texto ─────────────────────────────────────────────
    $question = new Question('Ingresa el ID del website [1]: ', '1');
    $websiteId = $helper->ask($input, $output, $question);

    // ── Selección de opciones ──────────────────────────────────────
    $question = new ChoiceQuestion(
        '¿Qué tipo de exportación?',
        ['csv', 'json', 'xml'],
        0   // valor por defecto: csv
    );
    $formato = $helper->ask($input, $output, $question);

    $output->writeln("Exportando en formato: {$formato}");

    return Command::SUCCESS;
}
```

## Comando con tabla de resultados

Muy útil para reportes:

```php
use Symfony\Component\Console\Helper\Table;

protected function execute(InputInterface $input, OutputInterface $output): int
{
    $this->appState->setAreaCode(Area::AREA_FRONTEND);

    // Datos de ejemplo (vendrían de tu Repository)
    $productos = [
        ['SKU-001', 'Producto A', '$99.00', 'Publicado'],
        ['SKU-002', 'Producto B', '$149.00', 'Borrador'],
        ['SKU-003', 'Producto C', '$49.00', 'Publicado'],
    ];

    $table = new Table($output);
    $table
        ->setHeaders(['SKU', 'Nombre', 'Precio', 'Estado'])
        ->setRows($productos)
        ->render();

    $output->writeln(sprintf('<info>Total: %d productos</info>', count($productos)));

    return Command::SUCCESS;
}
```

Output:

```

| SKU-002  | Producto B | $149.00| Borrador  |
| SKU-003  | Producto C | $49.00 | Publicado |
+----------+------------+--------+-----------+
Total: 3 productos
```

## Múltiples comandos en un módulo

Agrega todos al mismo `di.xml`:

```xml
<type name="Magento\Framework\Console\CommandList">
    <arguments>
        <argument name="commands" xsi:type="array">
            <item name="mimodulo_sincronizar_productos"
                  xsi:type="object">MiVendor\MiModulo\Console\Command\SincronizarProductosCommand</item>

            <item name="mimodulo_exportar_clientes"
                  xsi:type="object">MiVendor\MiModulo\Console\Command\ExportarClientesCommand</item>

            <item name="mimodulo_limpiar_datos"
                  xsi:type="object">MiVendor\MiModulo\Console\Command\LimpiarDatosCommand</item>
        </argument>
    </arguments>
</type>
```

## Códigos de retorno

```php
return Command::SUCCESS;   // 0 — todo bien
return Command::FAILURE;   // 1 — error
return Command::INVALID;   // 2 — uso incorrecto del comando
```

Los scripts de CI/CD usan estos códigos para saber si el comando falló:

```bash
php bin/magento mimodulo:productos:sincronizar full
if [ $? -ne 0 ]; then
    echo "Sincronización falló" | mail -s "ERROR" admin@tienda.com
fi
```

## Resumen

```
1. Clase extends Command en Console/Command/
2. configure() → nombre, descripción, argumentos, opciones
3. execute()   → setAreaCode() + lógica + return SUCCESS/FAILURE
4. Registrar en etc/di.xml dentro de CommandList
5. php bin/magento setup:upgrade + cache:flush
6. php bin/magento tu:comando:nombre
```

### Tips profesionales

```
💡 Siempre setea el área al inicio de execute()
💡 Usa --dry-run en comandos destructivos
💡 Usa niveles de verbosidad (-v/-vv/-vvv) para debug
💡 Retorna los códigos correctos para CI/CD
💡 Usa Progress Bar para operaciones largas
💡 Usa Table para mostrar listas de datos
```
