## SearchCriteria vs Query Builder de Laravel

🔄 **Laravel**: `Post::where('active', 1)->where('author_id', 5)->orderBy('created_at', 'desc')->paginate(10)`

En Magento, las queries a través de Repositories usan `SearchCriteria`:

```php
$searchCriteria = $this->searchCriteriaBuilder
    ->addFilter('is_active', 1)
    ->addFilter('author_id', 5)
    ->addSortOrder($this->sortOrderBuilder->setField('created_at')->setDescendingDirection()->create())
    ->setPageSize(10)
    ->setCurrentPage(1)
    ->create();

$result = $this->postRepository->getList($searchCriteria);
```

Es más verboso, pero es el contrato público — funciona con cualquier Repository, incluidos los de terceros y el core.

---

## Los componentes del sistema

```
SearchCriteriaBuilder   →  Constructor fluido del SearchCriteria
FilterBuilder           →  Construye filtros individuales (campo, valor, condición)
FilterGroupBuilder      →  Agrupa filtros con OR
SortOrderBuilder        →  Construye criterios de ordenamiento
SearchCriteria          →  El objeto final que se pasa al Repository
```

---

## Filtros simples — AND entre condiciones

```php
use Magento\Framework\Api\SearchCriteriaBuilder;

class PostService
{
    public function __construct(
        private readonly SearchCriteriaBuilder $searchCriteriaBuilder,
        private readonly PostRepositoryInterface $postRepository
    ) {}

    public function getActiveRecentPosts(): array
    {
        $searchCriteria = $this->searchCriteriaBuilder
            // Cada addFilter es un AND implícito
            ->addFilter('is_active', 1)
            ->addFilter('created_at', '2024-01-01', 'gteq')  // >= '2024-01-01'
            ->addFilter('title', '%Magento%', 'like')
            ->create();

        $result = $this->postRepository->getList($searchCriteria);
        return $result->getItems();
    }
}
```

**Condiciones disponibles** (tercer parámetro de `addFilter`):
```
eq      →  = (default)
neq     →  !=
gt      →  >
gteq    →  >=
lt      →  <
lteq    →  <=
like    →  LIKE
nlike   →  NOT LIKE
in      →  IN(...)
nin     →  NOT IN(...)
null    →  IS NULL
notnull →  IS NOT NULL
```

## Filtros OR — FilterGroups

Por defecto, cada `addFilter()` es un AND. Para crear OR necesitas `FilterBuilder` y `FilterGroupBuilder`:

```php
use Magento\Framework\Api\SearchCriteriaBuilder;
use Magento\Framework\Api\FilterBuilder;
use Magento\Framework\Api\Search\FilterGroupBuilder;

class PostService
{
    public function __construct(
        private readonly SearchCriteriaBuilder $searchCriteriaBuilder,
        private readonly FilterBuilder $filterBuilder,
        private readonly FilterGroupBuilder $filterGroupBuilder,
        private readonly PostRepositoryInterface $postRepository
    ) {}

    /**
     * Posts activos de categoría 1 O categoría 3
     * SQL: WHERE is_active = 1 AND (category_id = 1 OR category_id = 3)
     */
    public function getPostsFromCategories(array $categoryIds): array
    {
        // Filtro 1: is_active = 1 (AND)
        $activeFilter = $this->filterBuilder
            ->setField('is_active')
            ->setValue(1)
            ->setConditionType('eq')
            ->create();

        $activeGroup = $this->filterGroupBuilder
            ->addFilter($activeFilter)
            ->create();

        // Filtros OR: category_id IN [1, 3]
        // Opción más simple con 'in':
        $categoryFilter = $this->filterBuilder
            ->setField('category_id')
            ->setValue($categoryIds)
            ->setConditionType('in')
            ->create();

        $categoryGroup = $this->filterGroupBuilder
            ->addFilter($categoryFilter)
            ->create();

        // Construir SearchCriteria manualmente
        $searchCriteria = $this->searchCriteriaBuilder->create();
        $searchCriteria->setFilterGroups([$activeGroup, $categoryGroup]);

        return $this->postRepository->getList($searchCriteria)->getItems();
    }
}
```

### OR verdadero entre campos diferentes

```php
/**
 * Posts donde title LIKE '%php%' OR content LIKE '%php%'
 * SQL: WHERE (title LIKE '%php%' OR content LIKE '%php%')
 */
public function searchFullText(string $keyword): array
{
    $titleFilter = $this->filterBuilder
        ->setField('title')
        ->setValue('%' . $keyword . '%')
        ->setConditionType('like')
        ->create();

    $contentFilter = $this->filterBuilder
        ->setField('content')
        ->setValue('%' . $keyword . '%')
        ->setConditionType('like')
        ->create();

    // Los filtros en el MISMO FilterGroup son OR entre sí
    $orGroup = $this->filterGroupBuilder
        ->addFilter($titleFilter)
        ->addFilter($contentFilter)
        ->create();

    $searchCriteria = $this->searchCriteriaBuilder->create();
    $searchCriteria->setFilterGroups([$orGroup]);

    return $this->postRepository->getList($searchCriteria)->getItems();
}
```

**Regla clave**:
```
Filtros en FilterGroups DISTINTOS → AND entre grupos
Filtros en el MISMO FilterGroup  → OR entre ellos
```

## Ordenamiento

```php
use Magento\Framework\Api\SortOrderBuilder;
use Magento\Framework\Api\SortOrder;

class PostService
{
    public function __construct(
        private readonly SearchCriteriaBuilder $searchCriteriaBuilder,
        private readonly SortOrderBuilder $sortOrderBuilder,
        private readonly PostRepositoryInterface $postRepository
    ) {}

    public function getPostsSorted(): array
    {
        // Un campo de orden
        $sortOrder = $this->sortOrderBuilder
            ->setField('created_at')
            ->setDirection(SortOrder::SORT_DESC)
            ->create();

        // Varios campos de orden
        $sortByDate = $this->sortOrderBuilder
            ->setField('created_at')
            ->setDescendingDirection()  // helper alias
            ->create();

        $sortByTitle = $this->sortOrderBuilder
            ->setField('title')
            ->setAscendingDirection()
            ->create();

        $searchCriteria = $this->searchCriteriaBuilder
            ->addFilter('is_active', 1)
            ->setSortOrders([$sortByDate, $sortByTitle])  // primero fecha, luego título
            ->create();

        return $this->postRepository->getList($searchCriteria)->getItems();
    }
}
```

$searchCriteria = $this->searchCriteriaBuilder
    ->addFilter('is_active', 1)
    ->setPageSize(20)        // 20 por página
    ->setCurrentPage(3)      // Página 3 → OFFSET 40
    ->create();

$result = $this->postRepository->getList($searchCriteria);

$items      = $result->getItems();       // Los 20 items de la página 3
$totalCount = $result->getTotalCount();  // Total de registros (sin paginación)

## Ejemplo completo: búsqueda paginada con OR y orden

```php
public function search(
    string $keyword,
    int $page = 1,
    int $pageSize = 10,
    string $sortField = 'created_at',
    string $sortDir = 'DESC'
): array {
    // Filtros de búsqueda (OR entre título y contenido)
    $titleFilter = $this->filterBuilder
        ->setField('title')->setValue('%' . $keyword . '%')->setConditionType('like')->create();

    $contentFilter = $this->filterBuilder
        ->setField('content')->setValue('%' . $keyword . '%')->setConditionType('like')->create();

    $searchGroup = $this->filterGroupBuilder
        ->addFilter($titleFilter)->addFilter($contentFilter)->create();

    // Filtro is_active (AND con el grupo anterior)
    $activeFilter = $this->filterBuilder
        ->setField('is_active')->setValue(1)->setConditionType('eq')->create();
    $activeGroup = $this->filterGroupBuilder->addFilter($activeFilter)->create();

    // Orden
    $sortOrder = $this->sortOrderBuilder
        ->setField($sortField)
        ->setDirection($sortDir === 'DESC' ? SortOrder::SORT_DESC : SortOrder::SORT_ASC)
        ->create();

    // SearchCriteria completo
    $searchCriteria = $this->searchCriteriaBuilder->create();
    $searchCriteria->setFilterGroups([$searchGroup, $activeGroup]);
    $searchCriteria->setSortOrders([$sortOrder]);
    $searchCriteria->setPageSize($pageSize);
    $searchCriteria->setCurrentPage($page);

    $result = $this->postRepository->getList($searchCriteria);

    return [
        'items'       => $result->getItems(),
        'total_count' => $result->getTotalCount(),
        'page_size'   => $pageSize,
        'current_page'=> $page,
    ];
}
```

## SearchCriteria con el core de Magento

SearchCriteria funciona exactamente igual con los repositories del core:

```php
use Magento\Catalog\Api\ProductRepositoryInterface;

// Obtener productos de una categoría que estén en stock
$searchCriteria = $this->searchCriteriaBuilder
    ->addFilter('category_id', 5)
    ->addFilter('status', \Magento\Catalog\Model\Product\Attribute\Source\Status::STATUS_ENABLED)
    ->addFilter('type_id', 'simple')
    ->setPageSize(50)
    ->create();

$result = $this->productRepository->getList($searchCriteria);
```

## Resumen

```
SearchCriteriaBuilder
  addFilter(campo, valor, condición='eq')  →  AND implícito
  setSortOrders([...])                     →  ORDER BY
  setPageSize(N)                           →  LIMIT N
  setCurrentPage(N)                        →  OFFSET (N-1)*pageSize
  create()                                 →  SearchCriteria

FilterGroups y OR:
  Mismos FilterGroup → filtros con OR
  FilterGroups distintos → AND entre grupos

SortOrderBuilder
  setField() → setAscendingDirection()/setDescendingDirection() → create()

Resultado:
  getItems()      →  los registros de la página actual
  getTotalCount() →  total sin paginación (para calcular páginas)
```

## Ejercicios

### Ejercicio 1 — Query con múltiples condiciones

Usando `SearchCriteriaBuilder`, construye el SearchCriteria equivalente a:
```sql
WHERE is_active = 1
  AND (title LIKE '%oferta%' OR tag = 'sale')
  AND created_at >= '2024-06-01'
ORDER BY views_count DESC
LIMIT 10 OFFSET 0
```

<details>
<summary>Ver solución</summary>

```php
public function getSalePostsQuery(): SearchCriteriaInterface
{
    // Grupo 1: is_active = 1 (AND con los demás grupos)
    $activeFilter = $this->filterBuilder
        ->setField('is_active')->setValue(1)->setConditionType('eq')->create();
    $activeGroup = $this->filterGroupBuilder->addFilter($activeFilter)->create();

    // Grupo 2: title LIKE '%oferta%' OR tag = 'sale' (OR entre ellos)
    $titleFilter = $this->filterBuilder
        ->setField('title')->setValue('%oferta%')->setConditionType('like')->create();
    $tagFilter = $this->filterBuilder
        ->setField('tag')->setValue('sale')->setConditionType('eq')->create();
    $searchGroup = $this->filterGroupBuilder
        ->addFilter($titleFilter)->addFilter($tagFilter)->create();

    // Grupo 3: created_at >= '2024-06-01'
    $dateFilter = $this->filterBuilder
        ->setField('created_at')->setValue('2024-06-01')->setConditionType('gteq')->create();
    $dateGroup = $this->filterGroupBuilder->addFilter($dateFilter)->create();

    // Orden: views_count DESC
    $sortOrder = $this->sortOrderBuilder
        ->setField('views_count')->setDescendingDirection()->create();

    // SearchCriteria completo
    $searchCriteria = $this->searchCriteriaBuilder->create();
    $searchCriteria->setFilterGroups([$activeGroup, $searchGroup, $dateGroup]);
    $searchCriteria->setSortOrders([$sortOrder]);
    $searchCriteria->setPageSize(10);
    $searchCriteria->setCurrentPage(1);

    return $searchCriteria;
}
```

**La lógica de grupos**:
- `[$activeGroup, $searchGroup, $dateGroup]` → AND entre los tres grupos
- Dentro de `$searchGroup` hay dos filtros → OR entre title y tag

</details>

### Ejercicio 2 — Paginación correcta

Implementa un método `paginate(int $page, int $pageSize)` que use el Repository y devuelva:
- Los items de la página solicitada
- El total de páginas
- Si hay página siguiente / anterior

<details>
<summary>Ver solución</summary>

```php
public function paginate(int $page = 1, int $pageSize = 10): array
{
    $page = max(1, $page); // mínimo página 1

    $searchCriteria = $this->searchCriteriaBuilder
        ->addFilter('is_active', 1)
        ->setPageSize($pageSize)
        ->setCurrentPage($page)
        ->create();

    $result = $this->postRepository->getList($searchCriteria);

    $totalCount = $result->getTotalCount();
    $totalPages = (int) ceil($totalCount / $pageSize);

    return [
        'items'         => $result->getItems(),
        'total_count'   => $totalCount,
        'page_size'     => $pageSize,
        'current_page'  => $page,
        'total_pages'   => $totalPages,
        'has_previous'  => $page > 1,
        'has_next'      => $page < $totalPages,
    ];
}
```

**Caso borde importante**: Si `$pageSize = 0`, `ceil()` da infinito y la query puede devolver todos los registros. Siempre valida que `$pageSize >= 1`.

</details>
