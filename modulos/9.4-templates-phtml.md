## Los templates .phtml

Un archivo `.phtml` es PHP + HTML. La única diferencia con HTML puro es que tienes acceso a la variable `$block` — la instancia del Block que renderiza este template.

🔄 **Laravel**: Los templates Blade tienen `@{{ }}`, `@if`, `@foreach` y las variables son inyectadas explícitamente. En `.phtml` usas PHP estándar y accedes al Block directamente.

```php
<!-- view/frontend/templates/post/view.phtml -->
<?php
/** @var \MiVendor\Blog\Block\Post\View $block */
$post = $block->getPost();
?>

<article class="blog-post">
    <h1 class="post-title"><?= $block->escapeHtml($post->getTitle()) ?></h1>

    <div class="post-meta">
        <time datetime="<?= $block->escapeHtmlAttr($post->getCreatedAt()) ?>">
            <?= $block->escapeHtml($block->formatDate($post->getCreatedAt())) ?>
        </time>
    </div>

    <div class="post-content">
        <?= /* @noEscape */ $post->getContent() ?>
    </div>

    <a href="<?= $block->escapeUrl($block->getUrl('blog/post/view', ['id' => $post->getPostId()])) ?>"
       class="btn">
        <?= $block->escapeHtml(__('Read more')) ?>
    </a>
</article>
```

## Variables disponibles en cualquier template

```php
$block          // La instancia del Block asociado
$this           // Lo mismo que $block (legacy, preferir $block)
__('Texto')     // Helper global de traducción (disponible sin $block)
```

---

## Acceder a datos del Block

```php
// Via métodos del Block:
$post    = $block->getPost();
$title   = $block->getPostTitle();
$maxItems = $block->getMaxPosts();

// Via getData() — argumentos del XML:
$showAuthor = $block->getData('show_author');  // true/false
$cssClass   = $block->getData('css_class');

// Via getter mágico (camelCase → snake_case):
$showAuthor = $block->getShowAuthor();   // equivalente a getData('show_author')
$cssClass   = $block->getCssClass();
```

---

## Escape de salida — la regla de oro

**Siempre** escapar antes de outputear. Nunca confiar en que el dato ya viene limpio.

```php
// Texto dentro de HTML:
<?= $block->escapeHtml($variable) ?>

// Atributos HTML:
<div class="<?= $block->escapeHtmlAttr($cssClass) ?>">
<input value="<?= $block->escapeHtmlAttr($value) ?>">

// URLs:
<a href="<?= $block->escapeUrl($url) ?>">

// Dentro de JavaScript:
<script>
var name = '<?= $block->escapeJs($name) ?>';
</script>

// HTML ya sanitizado (WYSIWYG del admin, contenido confiable):
<?= /* @noEscape */ $block->getHtmlContent() ?>

// Números — cast es suficiente:
<span data-id="<?= (int) $post->getId() ?>">

// Null-safe:
<?= $block->escapeHtml($post?->getTitle() ?? '') ?>
```

## Traducciones

```php
// Función global (disponible en templates):
<?= __('Add to Cart') ?>
<?= __('Hello, %1', $customerName) ?>   // con placeholder
<?= __('%1 items in your cart', $count) ?>

// Plural:
<?= $count === 1 ? __('1 item') : __('%1 items', $count) ?>

// Con escape:
<?= $block->escapeHtml(__('Save %1%', $discount)) ?>
```

## PHP alternativo — la sintaxis preferida en templates

Preferir la sintaxis alternativa de PHP sobre llaves `{}` para mejor legibilidad:

```php
<!-- ✅ Sintaxis alternativa (recomendada en templates) -->
<?php if ($post->isActive()): ?>
    <span class="active"><?= __('Active') ?></span>
<?php elseif ($post->isDraft()): ?>
    <span class="draft"><?= __('Draft') ?></span>
<?php else: ?>
    <span class="inactive"><?= __('Inactive') ?></span>
<?php endif; ?>

<?php foreach ($block->getPosts() as $post): ?>
    <li><?= $block->escapeHtml($post->getTitle()) ?></li>
<?php endforeach; ?>

<!-- ❌ Evitar en templates (dificulta la lectura mezclado con HTML) -->
<?php if ($post->isActive()) { ?>
    <span>Active</span>
<?php } ?>
```

## Renderizar blocks hijos

```php
<!-- Renderizar un hijo específico por alias -->
<?= $block->getChildHtml('author') ?>
<?= $block->getChildHtml('tags') ?>

<!-- Renderizar todos los hijos en orden -->
<?= $block->getChildHtml() ?>

<!-- Obtener el objeto Block hijo para llamar métodos -->
<?php $authorBlock = $block->getChildBlock('author'); ?>
<?php if ($authorBlock && $authorBlock->getAuthor()): ?>
    <?= $block->getChildHtml('author') ?>
<?php endif; ?>
```

```php
<!-- URL de una imagen en view/frontend/web/images/ -->

```

## Fechas y precios

```php
// Formatear fechas:
<?= $block->escapeHtml($block->formatDate(
    $post->getCreatedAt(),
    \IntlDateFormatter::MEDIUM,
    false  // sin hora
)) ?>

// O con el helper de fecha:
<?php
$date = $this->_localeDate->date(new \DateTime($post->getCreatedAt()));
echo $block->escapeHtml($date->format('d/m/Y'));
?>

// Formatear precios (en blocks de catálogo):
<?= $block->escapeHtml($block->getProductPrice($product)) ?>
```

## Paginador

```php
<!-- Renderizar el paginador si existe como hijo -->
<?php if ($block->getChildBlock('pager')): ?>
    <div class="blog-pager">
        <?= $block->getChildHtml('pager') ?>
    </div>
<?php endif; ?>
```

```php
// En el Block:
protected function _prepareLayout(): self
{
    parent::_prepareLayout();

    $pager = $this->getLayout()->createBlock(\Magento\Theme\Block\Html\Pager::class);
    $pager->setAvailableLimit([10 => 10, 20 => 20, 50 => 50])
          ->setCollection($this->getPostCollection());

    $this->setChild('pager', $pager);
    return $this;
}
```

## El docblock — documentar el tipo de `$block`

```php
<?php
/**
 * @var \MiVendor\Blog\Block\Post\View $block
 */
?>
```

Sin este comentario el IDE no sabe qué tipo es `$block` y no puede autocompletar los métodos. Siempre incluirlo al inicio del template.

---

## Template limpio vs template "fat"

```php
<!-- ❌ Template "fat" — lógica de negocio en el template -->
<?php
$collection = $objectManager->get(\MiVendor\Blog\Model\ResourceModel\Post\CollectionFactory::class)
    ->create()
    ->addFieldToFilter('is_active', 1)
    ->setOrder('created_at', 'DESC')
    ->setPageSize(5);
?>
<?php foreach ($collection as $post): ?>
    <h3><?= $post->getTitle() ?></h3>
<?php endforeach; ?>

<!-- ✅ Template limpio — delega al Block -->
<?php foreach ($block->getRecentPosts() as $post): ?>
    <h3><?= $block->escapeHtml($post->getTitle()) ?></h3>
<?php endforeach; ?>
```

**Regla**: El template solo hace loops, ifs y escape. Toda la lógica va en el Block.

**Nunca usar `$objectManager` en templates** — es el equivalente a `new` directo, rompe DI.

---

## Resumen

```
$block          →  instancia del Block asociado
__('texto')     →  traducción

Escape (SIEMPRE):
  escapeHtml()       →  texto en HTML
  escapeHtmlAttr()   →  atributos HTML
  escapeUrl()        →  URLs
  escapeJs()         →  strings en JavaScript
  /* @noEscape */    →  HTML confiable (con comentario)

Sintaxis: PHP alternativo (if/endif, foreach/endforeach)
Docblock: @var Block al inicio del template

Regla de oro: lógica en el Block, presentación en el template
```

## Ejercicios

### Ejercicio 1 — Template completo de listado

Escribe el template `sidebar/recent-posts.phtml` que muestre los posts recientes del Block del módulo 9.3. Debe incluir: título con link, fecha y manejo correcto de escape.

<details>
<summary>Ver solución</summary>

```php
<?php
/** @var \MiVendor\Blog\Block\Sidebar\RecentPosts $block */
$posts = $block->getRecentPosts();
?>

<?php if (!empty($posts)): ?>
<div class="block block-blog-recent-posts">
    <div class="block-title">
        <strong><?= $block->escapeHtml(__('Recent Posts')) ?></strong>
    </div>
    <div class="block-content">
        <ol class="minicart-items">
            <?php foreach ($posts as $post): ?>
            <li class="item">
                <a href="<?= $block->escapeUrl($block->getUrl('blog/post/view', ['id' => $post->getPostId()])) ?>"
                   title="<?= $block->escapeHtmlAttr($post->getTitle()) ?>">
                    <?= $block->escapeHtml($post->getTitle()) ?>
                </a>
                <time class="post-date"
                      datetime="<?= $block->escapeHtmlAttr($post->getCreatedAt()) ?>">
                    <?= $block->escapeHtml(
                        $block->formatDate($post->getCreatedAt(), \IntlDateFormatter::MEDIUM, false)
                    ) ?>
                </time>
            </li>
            <?php endforeach; ?>
        </ol>
    </div>
</div>
<?php endif; ?>
```

**Nota**: `escapeHtmlAttr()` en `title` y `datetime` — son atributos HTML. `escapeHtml()` para el texto visible. `escapeUrl()` para el `href`.

</details>

### Ejercicio 2 — Identificar vulnerabilidades XSS

¿Cuáles líneas de este template tienen problemas de seguridad?

```php
<h1><?= $post->getTitle() ?></h1>
<p class="author-<?= $post->getAuthorName() ?>">Autor</p>
<a href="/blog/<?= $slug ?>">Ver post</a>
<script>trackPost(<?= $post->getId() ?>, '<?= $post->getTitle() ?>')</script>
<?= $post->getContent() ?>
```

<details>
<summary>Ver solución</summary>

```php
<!-- Línea 1: XSS en texto HTML -->
<!-- ❌ --> <h1><?= $post->getTitle() ?></h1>
<!-- ✅ --> <h1><?= $block->escapeHtml($post->getTitle()) ?></h1>

<!-- Línea 2: XSS en atributo HTML (class injection) -->
<!-- ❌ --> <p class="author-<?= $post->getAuthorName() ?>">
<!-- ✅ --> <p class="author-<?= $block->escapeHtmlAttr($post->getAuthorName()) ?>">

<!-- Línea 3: XSS en URL (href injection, path traversal) -->
<!-- ❌ --> <a href="/blog/<?= $slug ?>">
<!-- ✅ --> <a href="<?= $block->escapeUrl($block->getUrl('blog/post/view', ['slug' => $slug])) ?>">

<!-- Línea 4: JS injection — string sin escape, int sin cast -->
<!-- ❌ --> <script>trackPost(<?= $post->getId() ?>, '<?= $post->getTitle() ?>')</script>
<!-- ✅ --> <script>trackPost(<?= (int) $post->getId() ?>, '<?= $block->escapeJs($post->getTitle()) ?>')</script>

<!-- Línea 5: HTML del WYSIWYG — potencialmente confiable, requiere comentario explícito -->
<!-- ❌ --> <?= $post->getContent() ?>
<!-- ✅ --> <?= /* @noEscape */ $post->getContent() ?>
<!-- (asumiendo que el contenido se sanitizó al guardarlo — si no, usar HTMLPurifier) -->
```

**Los 5 vectores de XSS en templates**:
1. Texto en HTML → `escapeHtml()`
2. Atributos → `escapeHtmlAttr()`
3. URLs → `escapeUrl()`
4. JavaScript → `escapeJs()` + cast para números
5. HTML raw → `/* @noEscape */` + garantía de sanitización previa

</details>
