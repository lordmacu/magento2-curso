## Cuándo usar Collection directa vs SearchCriteria

```
SearchCriteria + Repository:
  ✅ APIs públicas del módulo
  ✅ Cuando el contrato importa (consumido por otros módulos o API REST)
  ❌ Joins complejos
  ❌ GROUP BY / HAVING
  ❌ Subqueries

Collection directa:
  ✅ Queries internas del módulo
  ✅ Joins con otras tablas
  ✅ Agregaciones (COUNT, SUM, AVG)
  ✅ Subqueries
  ❌ API pública (rompería el contrato si cambias la implementación)
```

## El objeto `Select` — base de todo

Las Collections de Magento usan internamente `Zend_Db_Select` (ahora `Laminas\Db`). El query se construye con métodos encadenables:

```php
$collection = $this->postCollectionFactory->create();

// Acceder al objeto Select directamente
$select = $collection->getSelect();

// Ver el SQL que se va a ejecutar
echo $select->__toString();
// → SELECT `main_table`.* FROM `mivendor_blog_post` AS `main_table`
```

## Joins básicos

```php
class Collection extends AbstractCollection
{
    public function joinWithCategory(): self
    {
        $this->getSelect()->join(
            // ['alias' => 'nombre_real_tabla']  o  solo 'nombre_tabla'
            ['cat' => $this->getTable('mivendor_blog_category')],
            // Condición ON
            'main_table.category_id = cat.category_id',
            // Columnas a traer: ['alias_en_resultado' => 'alias_tabla.columna']
            ['category_name' => 'cat.name', 'category_slug' => 'cat.url_key']
        );

        return $this;
    }

    public function joinWithCategoryOptional(): self
    {
        // LEFT JOIN — posts sin categoría también aparecen
        $this->getSelect()->joinLeft(
            ['cat' => $this->getTable('mivendor_blog_category')],
            'main_table.category_id = cat.category_id',
            ['category_name' => 'COALESCE(cat.name, "Sin categoría")']
        );

        return $this;
    }
}

// Uso:
$collection = $this->postCollectionFactory->create();
$collection->joinWithCategory()
           ->addFieldToFilter('cat.is_active', 1)  // filtrar por columna del join
           ->addActiveFilter();

foreach ($collection as $post) {
    echo $post->getCategoryName();  // columna del join disponible como getData()
}
```

## GROUP BY y agregaciones

```php
public function getPostCountByCategory(): array
{
    $collection = $this->postCollectionFactory->create();

    $collection->getSelect()
        ->reset(\Zend_Db_Select::COLUMNS)  // limpiar columnas por defecto
        ->columns([
            'category_id'  => 'main_table.category_id',
            'post_count'   => new \Zend_Db_Expr('COUNT(main_table.post_id)'),
            'total_views'  => new \Zend_Db_Expr('SUM(main_table.views_count)'),
            'avg_views'    => new \Zend_Db_Expr('AVG(main_table.views_count)'),
        ])
        ->join(
            ['cat' => $this->getTable('mivendor_blog_category')],
            'main_table.category_id = cat.category_id',
            ['category_name' => 'cat.name']
        )
        ->where('main_table.is_active = ?', 1)
        ->group('main_table.category_id')
        ->having('COUNT(main_table.post_id) > ?', 5)  // solo categorías con más de 5 posts
        ->order('post_count DESC');

    // No iterar como Models — usar fetchAll directamente
    $connection = $collection->getConnection();
    return $connection->fetchAll($collection->getSelect());
}
```

## Subqueries

```php
public function getPostsWithCommentCount(): self
{
    // Subquery: COUNT de comentarios por post
    $commentSubquery = new \Zend_Db_Expr(
        '(SELECT COUNT(*) FROM `' . $this->getTable('mivendor_blog_comment') . '`
          WHERE post_id = main_table.post_id AND is_approved = 1)'
    );

    $this->getSelect()->columns(['comment_count' => $commentSubquery]);
    return $this;
}

// Filtrar por resultados de subquery
public function hasMinimumComments(int $minComments): self
{
    $subquery = new \Zend_Db_Expr(
        '(SELECT COUNT(*) FROM `' . $this->getTable('mivendor_blog_comment') . '`
          WHERE post_id = main_table.post_id)'
    );

    $this->getSelect()->where("{$subquery} >= ?", $minComments);
    return $this;
}
```

## Queries directas con ResourceConnection

Cuando ni la Collection alcanza, usa la conexión directamente:

```php
use Magento\Framework\App\ResourceConnection;

class PostAnalytics
{
    public function __construct(
        private readonly ResourceConnection $resourceConnection
    ) {}

    public function getTopPostsByMonth(int $year, int $month): array
    {
        $connection = $this->resourceConnection->getConnection();

        $select = $connection->select()
            ->from(
                ['p' => $connection->getTableName('mivendor_blog_post')],
                ['post_id', 'title', 'views_count', 'created_at']
            )
            ->where('YEAR(p.created_at) = ?', $year)
            ->where('MONTH(p.created_at) = ?', $month)
            ->where('p.is_active = ?', 1)
            ->order('p.views_count DESC')
            ->limit(10);

        return $connection->fetchAll($select);
    }

    public function getDailyStats(string $dateFrom, string $dateTo): array
    {
        $connection = $this->resourceConnection->getConnection();
        $table = $connection->getTableName('mivendor_blog_post');

        // Raw SQL para queries muy complejas
        $sql = "
            SELECT
                DATE(created_at) as date,
                COUNT(*) as posts_created,
                SUM(views_count) as total_views,
                AVG(views_count) as avg_views
            FROM `{$table}`
            WHERE created_at BETWEEN :date_from AND :date_to
              AND is_active = 1
            GROUP BY DATE(created_at)
            ORDER BY date DESC
        ";

        // Usar bindings para evitar SQL injection
        return $connection->fetchAll($sql, [
            'date_from' => $dateFrom . ' 00:00:00',
            'date_to'   => $dateTo   . ' 23:59:59',
        ]);
    }
}
```

## Métodos de fetch de la conexión

```php
$connection = $this->resourceConnection->getConnection();

// Devuelve array de arrays
$rows = $connection->fetchAll($select);
// → [['post_id' => 1, 'title' => '...'], [...], ...]

// Devuelve solo la primera fila
$row = $connection->fetchRow($select);
// → ['post_id' => 1, 'title' => '...']

// Devuelve la primera columna de todas las filas
$ids = $connection->fetchCol($select);
// → [1, 5, 12, 33]

// Devuelve el primer valor de la primera fila (escalar)
$count = $connection->fetchOne($select);
// → 42

// Devuelve array clave => valor (primera col = key, segunda = value)
$map = $connection->fetchPairs($select);
// → [1 => 'Post uno', 5 => 'Post cinco', ...]
```

## INSERT, UPDATE, DELETE directos

```php
// INSERT
$connection->insert($tableName, [
    'title'     => 'Post nuevo',
    'is_active' => 1,
    'created_at'=> date('Y-m-d H:i:s'),
]);

// INSERT múltiple
$connection->insertMultiple($tableName, [
    ['title' => 'Post A', 'is_active' => 1],
    ['title' => 'Post B', 'is_active' => 0],
]);

// INSERT o UPDATE si ya existe (ON DUPLICATE KEY UPDATE)
$connection->insertOnDuplicate($tableName,
    ['post_id' => 1, 'views_count' => 150],
    ['views_count']  // columnas a actualizar si duplicado
);

// UPDATE con WHERE
$connection->update(
    $tableName,
    ['views_count' => new \Zend_Db_Expr('views_count + 1')],
    ['post_id = ?' => 42]
);

// DELETE con WHERE
$connection->delete(
    $tableName,
    ['post_id IN (?)' => [1, 5, 12]]
);
```

```php
$collection = $this->postCollectionFactory->create();
$collection->joinWithCategory()
           ->getPostsWithCommentCount();

foreach ($collection as $post) {
    // Columnas del join y columnas calculadas disponibles via getData()

    echo $post->getCommentCount();   // subquery
    echo $post->getData('avg_views'); // agregación
}
```

## Resumen

```
Collection::getSelect()   →  objeto Zend_Db_Select
  ->join()                →  INNER JOIN
  ->joinLeft()            →  LEFT JOIN
  ->columns()             →  SELECT columnas adicionales
  ->group()               →  GROUP BY
  ->having()              →  HAVING
  ->where()               →  WHERE adicional
  ->order()               →  ORDER BY
  ->limit()               →  LIMIT

ResourceConnection:
  ->fetchAll($select)     →  array de arrays
  ->fetchRow($select)     →  primera fila
  ->fetchCol($select)     →  primera columna de cada fila
  ->fetchOne($select)     →  escalar (primer valor)
  ->fetchPairs($select)   →  key => value

INSERT/UPDATE/DELETE:
  ->insert(), ->insertMultiple(), ->insertOnDuplicate()
  ->update($table, $data, $where)
  ->delete($table, $where)
```

## Ejercicios

### Ejercicio 1 — Join con agregación

Escribe un método en la Collection de posts que devuelva los 5 autores más prolíficos, con su nombre y cantidad de posts activos publicados.

<details>
<summary>Ver solución</summary>

```php
// En un servicio (no en la Collection — esta query no devuelve Models)
public function getTopAuthors(int $limit = 5): array
{
    $connection = $this->resourceConnection->getConnection();

    $select = $connection->select()
        ->from(
            ['p' => $connection->getTableName('mivendor_blog_post')],
            []  // sin columnas de la tabla principal
        )
        ->join(
            ['u' => $connection->getTableName('admin_user')],
            'p.author_id = u.user_id',
            [
                'author_id'   => 'u.user_id',
                'author_name' => new \Zend_Db_Expr("CONCAT(u.firstname, ' ', u.lastname)"),
                'author_email'=> 'u.email',
            ]
        )
        ->columns(['post_count' => new \Zend_Db_Expr('COUNT(p.post_id)')])
        ->where('p.is_active = ?', 1)
        ->group('p.author_id')
        ->order('post_count DESC')
        ->limit($limit);

    return $connection->fetchAll($select);
}

// Resultado:
// [
//   ['author_id' => 3, 'author_name' => 'Juan García', 'post_count' => 42],
//   ['author_id' => 7, 'author_name' => 'María López', 'post_count' => 31],
//   ...
// ]
```

**Por qué no usar Collection aquí**: El resultado son datos agregados (un row por autor), no instancias del Model `Post`. Para resultados no-Model, usar `ResourceConnection` directamente es más apropiado.

</details>

### Ejercicio 2 — Update masivo eficiente

Tienes 10,000 posts y necesitas incrementar `views_count` en 1 para una lista de IDs recibida. Escribe el código más eficiente posible (sin cargar los Models).

<details>
<summary>Ver solución</summary>

```php
public function incrementViews(array $postIds): void
{
    if (empty($postIds)) {
        return;
    }

    $connection = $this->resourceConnection->getConnection();
    $table = $connection->getTableName('mivendor_blog_post');

    // Un solo UPDATE con IN — eficiente para cualquier cantidad de IDs
    $connection->update(
        $table,
        ['views_count' => new \Zend_Db_Expr('views_count + 1')],
        ['post_id IN (?)' => $postIds]
    );
}

// Alternativa con insertOnDuplicate para tracking más preciso:
public function trackView(int $postId): void
{
    $connection = $this->resourceConnection->getConnection();
    $table = $connection->getTableName('mivendor_blog_post');

    // Incremento atómico — seguro en concurrencia
    $connection->query(
        "UPDATE `{$table}` SET views_count = views_count + 1 WHERE post_id = ?",
        [$postId]
    );
}
```

**Por qué NO usar Models aquí**:
```php
// ❌ Ineficiente — N queries (una por post)
foreach ($postIds as $postId) {
    $post = $this->postFactory->create();
    $this->postResource->load($post, $postId);
    $post->setViewsCount($post->getViewsCount() + 1);
    $this->postResource->save($post);
}

// ✅ Eficiente — 1 solo query
$connection->update($table,
    ['views_count' => new \Zend_Db_Expr('views_count + 1')],
    ['post_id IN (?)' => $postIds]
);
```

</details>
