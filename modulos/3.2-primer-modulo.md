# 3.2 — Crear tu Primer Módulo desde Cero

> **Objetivo**: Crear un módulo funcional paso a paso, entender cada archivo que se crea y por qué, y tener la base sobre la que construirás todo lo demás.

## Lo que vamos a construir

Un módulo llamado `MiVendor_Blog` — simple pero real. Al final tendrás:

- El módulo registrado y habilitado
- Una ruta frontend: `/blog`
- Un controller que responde con JSON
- Una página HTML básica

Todo construido desde cero, archivo por archivo.

---

## Paso 1 — Crear la estructura de directorios

```bash
mkdir -p app/code/MiVendor/Blog/etc/frontend
```

```
app/code/MiVendor/Blog/
├── etc/
│   ├── module.xml
│   └── frontend/
│       └── routes.xml
└── registration.php
```

---

## Paso 2 — registration.php

```php
<?php
// app/code/MiVendor/Blog/registration.php

use Magento\Framework\Component\ComponentRegistrar;

ComponentRegistrar::register(
    ComponentRegistrar::MODULE,
    'MiVendor_Blog',
    __DIR__
);
```

Sin este archivo, Magento no sabe que el módulo existe. Es lo primero que se carga.

---

## Paso 3 — etc/module.xml

```xml
<?xml version="1.0"?>
<!-- app/code/MiVendor/Blog/etc/module.xml -->
<config xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
        xsi:noNamespaceSchemaLocation="urn:magento:framework:Module/etc/module.xsd">

    <module name="MiVendor_Blog" setup_version="1.0.0"/>

</config>
```

Por ahora sin dependencias — las agregaremos cuando las necesitemos.

---

## Paso 4 — Habilitar el módulo

```bash
php bin/magento module:enable MiVendor_Blog
php bin/magento setup:upgrade
php bin/magento cache:flush
```

Verificar:
```bash
php bin/magento module:status MiVendor_Blog
# MiVendor_Blog : Module is enabled
```

En `app/etc/config.php` ahora aparece:
```php
'MiVendor_Blog' => 1,
```

---

## Paso 5 — Registrar una ruta (URL)

```xml
<?xml version="1.0"?>
<!-- app/code/MiVendor/Blog/etc/frontend/routes.xml -->
<config xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
        xsi:noNamespaceSchemaLocation="urn:magento:framework:App/etc/routes.xsd">

    <router id="standard">
        <route id="blog" frontName="blog">
            <module name="MiVendor_Blog"/>
        </route>
    </router>

</config>
```

- `id="blog"` — identificador interno de la ruta
- `frontName="blog"` — el segmento que aparece en la URL: `/blog/...`
- El router **standard** mapea: `/{frontName}/{controller}/{action}`

Con esto, Magento buscará controllers en `MiVendor/Blog/Controller/`.

---

## Paso 6 — Crear el primer Controller

```bash
mkdir -p app/code/MiVendor/Blog/Controller/Index
```

```php
<?php
// app/code/MiVendor/Blog/Controller/Index/Index.php
namespace MiVendor\Blog\Controller\Index;

use Magento\Framework\App\Action\HttpGetActionInterface;
use Magento\Framework\Controller\Result\JsonFactory;

class Index implements HttpGetActionInterface
{
    public function __construct(
        private readonly JsonFactory $resultJsonFactory
    ) {}

    public function execute(): \Magento\Framework\Controller\ResultInterface
    {
        $result = $this->resultJsonFactory->create();
        $result->setData([
            'module'  => 'MiVendor_Blog',
            'status'  => 'funcionando',
            'message' => '¡Mi primer módulo!'
        ]);

        return $result;
    }
}
```

La URL para acceder: `http://localhost:8181/blog/index/index`

O simplemente `http://localhost:8181/blog` — Magento usa `index/index` como default cuando no se especifica controller/action.

```bash
php bin/magento cache:flush
```

---

## Paso 7 — Controller que devuelve una página HTML

Ahora hagamos uno que renderice una página completa con layout:

```bash
mkdir -p app/code/MiVendor/Blog/Controller/Post
mkdir -p app/code/MiVendor/Blog/view/frontend/layout
mkdir -p app/code/MiVendor/Blog/view/frontend/templates/post
```

```php
<?php
// app/code/MiVendor/Blog/Controller/Post/View.php
namespace MiVendor\Blog\Controller\Post;

use Magento\Framework\App\Action\HttpGetActionInterface;
use Magento\Framework\View\Result\PageFactory;

class View implements HttpGetActionInterface
{
    public function __construct(
        private readonly PageFactory $resultPageFactory
    ) {}

    public function execute(): \Magento\Framework\Controller\ResultInterface
    {
        $page = $this->resultPageFactory->create();
        $page->getConfig()->getTitle()->set('Mi Blog');

        return $page;
    }
}
```

URL: `http://localhost:8181/blog/post/view`

---

## Paso 8 — Layout XML y Template

El controller devuelve una `Page`, Magento busca el layout XML con el handle `blog_post_view` (frontName + controller + action):

```xml
<?xml version="1.0"?>
<!-- app/code/MiVendor/Blog/view/frontend/layout/blog_post_view.xml -->
<page xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
      xsi:noNamespaceSchemaLocation="urn:magento:framework:View/Layout/etc/page_configuration.xsd">

    <body>
        <referenceContainer name="content">
            <block class="Magento\Framework\View\Element\Template"
                   name="blog.post.view"
                   template="MiVendor_Blog::post/view.phtml"/>
        </referenceContainer>
    </body>

</page>
```

```php
<?php
// app/code/MiVendor/Blog/view/frontend/templates/post/view.phtml
/** @var \Magento\Framework\View\Element\Template $block */
?>
<div class="blog-post">
    <h1><?= $block->escapeHtml('¡Hola desde MiVendor_Blog!') ?></h1>
    <p>Este es mi primer módulo de Magento funcionando.</p>
</div>
```

```bash
php bin/magento cache:flush
```

Abre `http://localhost:8181/blog/post/view` — verás la página con el tema de Magento y tu contenido dentro del `content` container.

## La estructura final del módulo

```
app/code/MiVendor/Blog/
├── registration.php
├── etc/
│   ├── module.xml
│   └── frontend/
│       └── routes.xml
├── Controller/
│   ├── Index/
│   │   └── Index.php          ← /blog  o  /blog/index/index
│   └── Post/
│       └── View.php           ← /blog/post/view
└── view/
    └── frontend/
        ├── layout/
        │   └── blog_post_view.xml
        └── templates/
            └── post/
                └── view.phtml
```

## Cómo Magento resuelve la URL

```
http://localhost:8181/blog/post/view
                      ↓     ↓    ↓
               frontName  ctrl  action

Magento busca:
app/code/MiVendor/Blog/Controller/Post/View.php
                                   ↑     ↑
                               carpeta  clase
```

Si la URL es `/blog` sin nada más:
```
/blog  →  /blog/index/index  (defaults)
→  Controller/Index/Index.php
```

## Errores comunes al crear tu primer módulo

### "No module registered for path"
```bash
# Causa: registration.php no se está cargando
# Solución:
composer dump-autoload
php bin/magento cache:flush
```

### La URL devuelve 404
```bash
# Causa 1: caché de rutas
php bin/magento cache:flush

# Causa 2: el módulo no está habilitado
php bin/magento module:status MiVendor_Blog

# Causa 3: el nombre del archivo/clase no coincide con la URL
# /blog/post/view  →  Controller/Post/View.php  →  class View
```

### "Area code not set" en el Controller
```bash
# Causa: estás inyectando algo que requiere un área seteada
# Solución: usa HttpGetActionInterface en lugar de extender Action
# El área se setea automáticamente con las interfaces de verbo HTTP
```

## Resumen

```
1. mkdir app/code/Vendor/Modulo/
2. registration.php  →  ComponentRegistrar::register()
3. etc/module.xml    →  <module name="Vendor_Modulo"/>
4. module:enable + setup:upgrade + cache:flush
5. etc/frontend/routes.xml  →  frontName para las URLs
6. Controller/{Carpeta}/{Clase}.php  →  implements HttpGetActionInterface
7. execute()  →  return $result (Json, Page, Redirect...)
8. Para Page: layout XML + template .phtml
```

## Ejercicios

### Ejercicio 1 — Nueva ruta y controller JSON

En el módulo `MiVendor_Blog` que creamos, agrega:
- Una ruta `/blog/api/status`
- Un controller que devuelva JSON con `{ "status": "ok", "module": "MiVendor_Blog", "timestamp": "..." }`

<details>
<summary>Ver solución</summary>

```php
// Controller/Api/Status.php
namespace MiVendor\Blog\Controller\Api;

use Magento\Framework\App\Action\HttpGetActionInterface;
use Magento\Framework\Controller\Result\JsonFactory;

class Status implements HttpGetActionInterface
{
    public function __construct(
        private readonly JsonFactory $resultJsonFactory
    ) {}

    public function execute(): \Magento\Framework\Controller\ResultInterface
    {
        $result = $this->resultJsonFactory->create();
        $result->setData([
            'status'    => 'ok',
            'module'    => 'MiVendor_Blog',
            'timestamp' => date('Y-m-d H:i:s'),
        ]);
        return $result;
    }
}
```

URL: `http://localhost:8181/blog/api/status`

El `routes.xml` ya existente con `frontName="blog"` cubre esta ruta automáticamente — no necesitas tocar nada más.

```bash
php bin/magento cache:flush
curl http://localhost:8181/blog/api/status
# {"status":"ok","module":"MiVendor_Blog","timestamp":"..."}
```

</details>

### Ejercicio 2 — Página con título dinámico

Agrega una ruta `/blog/post/index` que:
- Renderice una página completa con el tema de Magento
- El título sea "Blog — Posts Recientes"
- El contenido muestre un `<h1>` y un párrafo con texto de bienvenida

<details>
<summary>Ver solución</summary>

```php
// Controller/Post/Index.php
namespace MiVendor\Blog\Controller\Post;

use Magento\Framework\App\Action\HttpGetActionInterface;
use Magento\Framework\View\Result\PageFactory;

class Index implements HttpGetActionInterface
{
    public function __construct(
        private readonly PageFactory $resultPageFactory
    ) {}

    public function execute(): \Magento\Framework\Controller\ResultInterface
    {
        $page = $this->resultPageFactory->create();
        $page->getConfig()->getTitle()->set('Blog — Posts Recientes');
        return $page;
    }
}
```

```xml
<!-- view/frontend/layout/blog_post_index.xml -->
<page xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
      xsi:noNamespaceSchemaLocation="urn:magento:framework:View/Layout/etc/page_configuration.xsd">
    <body>
        <referenceContainer name="content">
            <block class="Magento\Framework\View\Element\Template"
                   name="blog.post.index"
                   template="MiVendor_Blog::post/index.phtml"/>
        </referenceContainer>
    </body>
</page>
```

```php
<!-- view/frontend/templates/post/index.phtml -->
<div class="blog-index">
    <h1><?= $block->escapeHtml('Posts Recientes') ?></h1>
    <p>Bienvenido al blog de MiVendor. Aquí encontrarás los últimos artículos.</p>
</div>
```

```bash
php bin/magento cache:flush
# Visitar: http://localhost:8181/blog/post/index
```

</details>
