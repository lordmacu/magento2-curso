## Por qué Repositories y no Model directo

🔄 **Laravel**: Los Eloquent Models son la API pública. Cualquier módulo puede llamar `Post::find()`, `Post::where()`, etc. Directo, simple, pero acoplado.

En Magento el problema de acoplar a los Models directamente es que:
1. Si cambias la implementación interna, rompes todos los que la usan
2. No puedes intercambiar implementaciones vía DI
3. No tienes un lugar natural para la caché de entidades
4. Los datos de terceros no tienen un contrato garantizado

**Service Contracts** resuelven esto con dos partes:
```
Api/PostRepositoryInterface        ← El contrato (interfaz pública)
Model/PostRepository               ← La implementación
```

Otros módulos dependen de `PostRepositoryInterface`, no de `PostRepository`. Puedes cambiar la implementación sin romper nada.

## La interfaz — Service Contract

```php
<?php
// Api/PostRepositoryInterface.php
namespace MiVendor\Blog\Api;

use MiVendor\Blog\Api\Data\PostInterface;
use Magento\Framework\Api\SearchCriteriaInterface;
use MiVendor\Blog\Api\Data\PostSearchResultsInterface;

interface PostRepositoryInterface
{
    /**
     * Obtener un post por ID
     * @throws \Magento\Framework\Exception\NoSuchEntityException
     */
    public function getById(int $postId): PostInterface;

    /**
     * Guardar un post (crear o actualizar)
     * @throws \Magento\Framework\Exception\CouldNotSaveException
     */
    public function save(PostInterface $post): PostInterface;

    /**
     * Eliminar un post
     * @throws \Magento\Framework\Exception\CouldNotDeleteException
     */
    public function delete(PostInterface $post): bool;

    /**
     * Eliminar por ID
     * @throws \Magento\Framework\Exception\NoSuchEntityException
     * @throws \Magento\Framework\Exception\CouldNotDeleteException
     */
    public function deleteById(int $postId): bool;

    /**
     * Buscar con criterios (paginación, filtros, orden)
     */
    public function getList(SearchCriteriaInterface $searchCriteria): PostSearchResultsInterface;
}
```

## El Model implementando la interfaz

```php
<?php
// Model/Post.php
namespace MiVendor\Blog\Model;

use Magento\Framework\Model\AbstractModel;
use MiVendor\Blog\Api\Data\PostInterface;

class Post extends AbstractModel implements PostInterface
{
    protected function _construct(): void
    {
        $this->_init(\MiVendor\Blog\Model\ResourceModel\Post::class);
    }

    public function getPostId(): ?int
    {
        return $this->getData(self::POST_ID) ? (int) $this->getData(self::POST_ID) : null;
    }

    public function setPostId(int $postId): self
    {
        return $this->setData(self::POST_ID, $postId);
    }

    public function getTitle(): string
    {
        return (string) $this->getData(self::TITLE);
    }

    public function setTitle(string $title): self
    {
        return $this->setData(self::TITLE, $title);
    }

    public function getUrlKey(): string
    {
        return (string) $this->getData(self::URL_KEY);
    }

    public function setUrlKey(string $urlKey): self
    {
        return $this->setData(self::URL_KEY, $urlKey);
    }

    public function getContent(): ?string
    {
        return $this->getData(self::CONTENT);
    }

    public function setContent(?string $content): self
    {
        return $this->setData(self::CONTENT, $content);
    }

    public function isActive(): bool
    {
        return (bool) $this->getData(self::IS_ACTIVE);
    }

    public function setIsActive(bool $isActive): self
    {
        return $this->setData(self::IS_ACTIVE, (int) $isActive);
    }

    public function getCreatedAt(): ?string
    {
        return $this->getData(self::CREATED_AT);
    }

    public function getUpdatedAt(): ?string
    {
        return $this->getData(self::UPDATED_AT);
    }
}
```

## La implementación del Repository

```php
<?php
// Model/PostRepository.php
namespace MiVendor\Blog\Model;

use MiVendor\Blog\Api\PostRepositoryInterface;
use MiVendor\Blog\Api\Data\PostInterface;
use MiVendor\Blog\Api\Data\PostSearchResultsInterface;
use MiVendor\Blog\Api\Data\PostSearchResultsInterfaceFactory;
use MiVendor\Blog\Model\PostFactory;
use MiVendor\Blog\Model\ResourceModel\Post as PostResource;
use MiVendor\Blog\Model\ResourceModel\Post\CollectionFactory;
use Magento\Framework\Api\SearchCriteriaInterface;
use Magento\Framework\Api\SearchCriteria\CollectionProcessorInterface;
use Magento\Framework\Exception\CouldNotDeleteException;
use Magento\Framework\Exception\CouldNotSaveException;
use Magento\Framework\Exception\NoSuchEntityException;

class PostRepository implements PostRepositoryInterface
{
    // Caché en memoria para la misma request (evita queries repetidas)
    private array $cache = [];

    public function __construct(
        private readonly PostFactory $postFactory,
        private readonly PostResource $postResource,
        private readonly CollectionFactory $collectionFactory,
        private readonly PostSearchResultsInterfaceFactory $searchResultsFactory,
        private readonly CollectionProcessorInterface $collectionProcessor
    ) {}

    public function getById(int $postId): PostInterface
    {
        // Revisar caché en memoria primero
        if (isset($this->cache[$postId])) {
            return $this->cache[$postId];
        }

        $post = $this->postFactory->create();
        $this->postResource->load($post, $postId);

        if (!$post->getPostId()) {
            throw new NoSuchEntityException(
                __('The post with ID "%1" doesn\'t exist.', $postId)
            );
        }

        $this->cache[$postId] = $post;
        return $post;
    }

    public function save(PostInterface $post): PostInterface
    {
        try {
            $this->postResource->save($post);
            // Actualizar caché con el objeto guardado
            $this->cache[$post->getPostId()] = $post;
        } catch (\Exception $e) {
            throw new CouldNotSaveException(
                __('Could not save the post: %1', $e->getMessage()),
                $e
            );
        }

        return $post;
    }

    public function delete(PostInterface $post): bool
    {
        try {
            $postId = $post->getPostId();
            $this->postResource->delete($post);
            // Limpiar de caché
            unset($this->cache[$postId]);
        } catch (\Exception $e) {
            throw new CouldNotDeleteException(
                __('Could not delete the post: %1', $e->getMessage()),
                $e
            );
        }

        return true;
    }

    public function deleteById(int $postId): bool
    {
        return $this->delete($this->getById($postId));
    }

    public function getList(SearchCriteriaInterface $searchCriteria): PostSearchResultsInterface
    {
        $collection = $this->collectionFactory->create();

        // CollectionProcessor aplica filtros, orden y paginación del SearchCriteria
        $this->collectionProcessor->process($searchCriteria, $collection);

        $searchResults = $this->searchResultsFactory->create();
        $searchResults->setSearchCriteria($searchCriteria);
        $searchResults->setItems($collection->getItems());
        $searchResults->setTotalCount($collection->getSize());

        return $searchResults;
    }
}
```

## SearchResults con la clase genérica

`Magento\Framework\Api\SearchResults` ya implementa `SearchResultsInterface`. Puedes usarla directamente para `PostSearchResultsInterface` si tu interfaz solo extiende `SearchResultsInterface` sin métodos adicionales:

```php
// Sin crear una clase concreta — usar la genérica de Magento
// En di.xml:
<preference for="MiVendor\Blog\Api\Data\PostSearchResultsInterface"
            type="Magento\Framework\Api\SearchResults"/>
```

## Usar el Repository

```php
use MiVendor\Blog\Api\PostRepositoryInterface;
use Magento\Framework\Api\SearchCriteriaBuilder;

class AlgunServicio
{
    public function __construct(
        private readonly PostRepositoryInterface $postRepository,
        private readonly SearchCriteriaBuilder $searchCriteriaBuilder
    ) {}

    public function getPostById(int $id): void
    {
        try {
            $post = $this->postRepository->getById($id);
            echo $post->getTitle();
        } catch (\Magento\Framework\Exception\NoSuchEntityException $e) {
            // El post no existe
        }
    }

    public function getActivePosts(): array
    {
        $searchCriteria = $this->searchCriteriaBuilder
            ->addFilter('is_active', 1)
            ->addSortOrder('created_at', 'DESC')  // módulo 8.6 explica esto
            ->setPageSize(10)
            ->setCurrentPage(1)
            ->create();

        $result = $this->postRepository->getList($searchCriteria);
        return $result->getItems();
    }

    public function createPost(string $title, string $urlKey): PostInterface
    {
        $post = $this->postFactory->create();
        $post->setTitle($title);
        $post->setUrlKey($urlKey);
        $post->setIsActive(true);

        return $this->postRepository->save($post);
    }
}
```

## Excepciones estándar de Magento

```php
use Magento\Framework\Exception\NoSuchEntityException;    // getById: no encontrado
use Magento\Framework\Exception\CouldNotSaveException;    // save: error al guardar
use Magento\Framework\Exception\CouldNotDeleteException;  // delete: error al eliminar
use Magento\Framework\Exception\LocalizedException;       // error genérico con mensaje user-friendly
use Magento\Framework\Exception\InputException;           // validación de inputs

// Al consumir el Repository:
try {
    $post = $this->postRepository->getById($id);
} catch (NoSuchEntityException $e) {
    // El post no existe → 404 o mensaje al usuario
} catch (LocalizedException $e) {
    // Error esperado con mensaje amigable
} catch (\Exception $e) {
    // Error inesperado → loguear y mensaje genérico
}
```

## Estructura completa de directorios

```
Api/
├── PostRepositoryInterface.php         ← Contrato del Repository
└── Data/
    ├── PostInterface.php               ← Contrato de la entidad
    └── PostSearchResultsInterface.php  ← Contrato de resultados

Model/
├── Post.php                            ← Model implementando PostInterface
└── PostRepository.php                  ← Implementación del Repository

etc/
└── di.xml                              ← Preferences: interfaz → implementación
```

---

## Resumen

```
PostRepositoryInterface   →  El contrato. Otros módulos dependen de esto.
PostRepository            →  La implementación concreta. Registrada en di.xml.
PostInterface             →  Contrato de la entidad (getters/setters).
PostSearchResultsInterface → Contrato para getList().

Exceptions:
  NoSuchEntityException    →  getById() no encontró nada
  CouldNotSaveException    →  save() falló
  CouldNotDeleteException  →  delete() falló

Caché en memoria:
  private array $cache = []  →  evita re-queries dentro de la misma request
```

### Ejercicio 1 — Repository completo para FAQ

Crea el contrato `QuestionRepositoryInterface` y su implementación `QuestionRepository` para el módulo FAQ. La interfaz debe tener: `getById`, `save`, `delete`, `deleteById`, `getList`.

<details>
<summary>Ver solución</summary>

```php
<?php
// Api/QuestionRepositoryInterface.php
namespace MiVendor\Faq\Api;

use MiVendor\Faq\Api\Data\QuestionInterface;
use Magento\Framework\Api\SearchCriteriaInterface;
use Magento\Framework\Api\SearchResultsInterface;

interface QuestionRepositoryInterface
{
    /** @throws \Magento\Framework\Exception\NoSuchEntityException */
    public function getById(int $questionId): QuestionInterface;

    /** @throws \Magento\Framework\Exception\CouldNotSaveException */
    public function save(QuestionInterface $question): QuestionInterface;

    /** @throws \Magento\Framework\Exception\CouldNotDeleteException */
    public function delete(QuestionInterface $question): bool;

    /** @throws \Magento\Framework\Exception\NoSuchEntityException|\Magento\Framework\Exception\CouldNotDeleteException */
    public function deleteById(int $questionId): bool;

    public function getList(SearchCriteriaInterface $searchCriteria): SearchResultsInterface;
}
```

```php
<?php
// Model/QuestionRepository.php
namespace MiVendor\Faq\Model;

use MiVendor\Faq\Api\QuestionRepositoryInterface;
use MiVendor\Faq\Api\Data\QuestionInterface;
use MiVendor\Faq\Model\QuestionFactory;
use MiVendor\Faq\Model\ResourceModel\Question as QuestionResource;
use MiVendor\Faq\Model\ResourceModel\Question\CollectionFactory;
use Magento\Framework\Api\SearchCriteriaInterface;
use Magento\Framework\Api\SearchResultsInterface;
use Magento\Framework\Api\SearchResultsInterfaceFactory;
use Magento\Framework\Api\SearchCriteria\CollectionProcessorInterface;
use Magento\Framework\Exception\{CouldNotDeleteException, CouldNotSaveException, NoSuchEntityException};

class QuestionRepository implements QuestionRepositoryInterface
{
    private array $cache = [];

    public function __construct(
        private readonly QuestionFactory $questionFactory,
        private readonly QuestionResource $questionResource,
        private readonly CollectionFactory $collectionFactory,
        private readonly SearchResultsInterfaceFactory $searchResultsFactory,
        private readonly CollectionProcessorInterface $collectionProcessor
    ) {}

    public function getById(int $questionId): QuestionInterface
    {
        if (isset($this->cache[$questionId])) {
            return $this->cache[$questionId];
        }

        $question = $this->questionFactory->create();
        $this->questionResource->load($question, $questionId);

        if (!$question->getId()) {
            throw new NoSuchEntityException(
                __('The question with ID "%1" doesn\'t exist.', $questionId)
            );
        }

        return $this->cache[$questionId] = $question;
    }

    public function save(QuestionInterface $question): QuestionInterface
    {
        try {
            $this->questionResource->save($question);
            $this->cache[$question->getId()] = $question;
        } catch (\Exception $e) {
            throw new CouldNotSaveException(__('Could not save the question: %1', $e->getMessage()), $e);
        }
        return $question;
    }

    public function delete(QuestionInterface $question): bool
    {
        try {
            $id = $question->getId();
            $this->questionResource->delete($question);
            unset($this->cache[$id]);
        } catch (\Exception $e) {
            throw new CouldNotDeleteException(__('Could not delete the question: %1', $e->getMessage()), $e);
        }
        return true;
    }

    public function deleteById(int $questionId): bool
    {
        return $this->delete($this->getById($questionId));
    }

    public function getList(SearchCriteriaInterface $searchCriteria): SearchResultsInterface
    {
        $collection = $this->collectionFactory->create();
        $this->collectionProcessor->process($searchCriteria, $collection);

        $searchResults = $this->searchResultsFactory->create();
        $searchResults->setSearchCriteria($searchCriteria);
        $searchResults->setItems($collection->getItems());
        $searchResults->setTotalCount($collection->getSize());
        return $searchResults;
    }
}
```

### Ejercicio 2 — Consumir el Repository correctamente

Escribe un servicio que:
1. Busque una pregunta por ID y devuelva `null` si no existe (sin propagar la excepción)
2. Cambie el `is_active` de una pregunta a `false` y la guarde
3. Maneje el caso en que `save()` falle con un mensaje de log

<details>
<summary>Ver solución</summary>

```php
<?php
namespace MiVendor\Faq\Model;

use MiVendor\Faq\Api\QuestionRepositoryInterface;
use MiVendor\Faq\Api\Data\QuestionInterface;
use Magento\Framework\Exception\NoSuchEntityException;
use Magento\Framework\Exception\CouldNotSaveException;
use Psr\Log\LoggerInterface;

class QuestionManager
{
    public function __construct(
        private readonly QuestionRepositoryInterface $questionRepository,
        private readonly LoggerInterface $logger
    ) {}

    /**
     * Buscar por ID — null si no existe
     */
    public function findById(int $id): ?QuestionInterface
    {
        try {
            return $this->questionRepository->getById($id);
        } catch (NoSuchEntityException $e) {
            return null;
        }
    }

    /**
     * Deshabilitar una pregunta — retorna false si no existe o falla
     */
    public function disable(int $questionId): bool
    {
        $question = $this->findById($questionId);

        if ($question === null) {
            $this->logger->warning(
                'Attempted to disable non-existent question ID ' . $questionId
            );
            return false;
        }

        $question->setIsActive(false);

        try {
            $this->questionRepository->save($question);
            return true;
        } catch (CouldNotSaveException $e) {
            $this->logger->error(
                'Failed to disable question ID ' . $questionId . ': ' . $e->getMessage()
            );
            return false;
        }
    }
}
```

**Por qué capturar `NoSuchEntityException` aquí**: El servicio convierte la excepción a `null` porque en este contexto "no existe" es un caso válido, no un error. Si fuera un controller, podrías lanzarla y mostrar un 404.
