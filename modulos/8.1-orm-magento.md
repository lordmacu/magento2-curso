## El problema con Eloquent

🔄 **Laravel**: Un Model de Eloquent hace todo — representa el objeto, accede a la base de datos, define relaciones y gestiona colecciones.

```php
// Laravel: una clase hace todo
$post = Post::find(42);
$post->title = 'Nuevo título';
$post->save();

$posts = Post::where('active', 1)->orderBy('created_at')->get();
```

En Magento esto se divide en tres responsabilidades:

```
Model          →  La entidad. Datos + getters/setters. NO sabe de DB.
ResourceModel  →  El acceso a DB. Sabe cómo leer/escribir en MySQL.
Collection     →  Queries de múltiples registros. Lazy loading.
```

---

## La Trinidad explicada

### 1. Model — La entidad

```php
<?php
// app/code/MiVendor/Blog/Model/Post.php
namespace MiVendor\Blog\Model;

use Magento\Framework\Model\AbstractModel;

class Post extends AbstractModel
{
    public const STATUS_ENABLED  = 1;
    public const STATUS_DISABLED = 0;

    protected function _construct(): void
    {
        // Le dice cuál es su ResourceModel
        $this->_init(\MiVendor\Blog\Model\ResourceModel\Post::class);
    }

    // Getters/Setters explícitos (opcional pero recomendado)
    public function getTitle(): string
    {
        return (string) $this->getData('title');
    }

    public function setTitle(string $title): self
    {
        return $this->setData('title', $title);
    }

    public function getContent(): string
    {
        return (string) $this->getData('content');
    }

    public function setContent(string $content): self
    {
        return $this->setData('content', $content);
    }

    public function getUrlKey(): string
    {
        return (string) $this->getData('url_key');
    }

    public function isActive(): bool
    {
        return (bool) $this->getData('is_active');
    }

    // Lógica de negocio que pertenece a la entidad
    public function getStatusLabel(): string
    {
        return $this->isActive() ? 'Enabled' : 'Disabled';
    }
}
```

**Hereda de `AbstractModel`**:
- `getData('campo')` / `setData('campo', $valor)` — acceso genérico
- `getId()` — el ID (PK)
- `save()` / `delete()` / `load()` — delega al ResourceModel (legacy, preferir Repository)

### 2. ResourceModel — Acceso a DB

```php
<?php
// app/code/MiVendor/Blog/Model/ResourceModel/Post.php
namespace MiVendor\Blog\Model\ResourceModel;

use Magento\Framework\Model\ResourceModel\Db\AbstractDb;

class Post extends AbstractDb
{
    protected function _construct(): void
    {
        // ('nombre_tabla', 'nombre_primary_key')
        $this->_init('mivendor_blog_post', 'post_id');
    }

    // Aquí van queries específicas que no entran en Collection
    public function getIdByUrlKey(string $urlKey): ?int
    {
        $connection = $this->getConnection();
        $select = $connection->select()
            ->from($this->getMainTable(), ['post_id'])
            ->where('url_key = ?', $urlKey)
            ->limit(1);

        $id = $connection->fetchOne($select);
        return $id ? (int) $id : null;
    }
}
```

**Hereda de `AbstractDb`**:
- `getConnection()` — la conexión MySQL
- `getMainTable()` — nombre de la tabla principal
- `load(Model, $id)` — cargar un registro por ID
- `save(Model)` — INSERT o UPDATE según si tiene ID
- `delete(Model)` — DELETE

### 3. Collection — Queries múltiples

```php
<?php
// app/code/MiVendor/Blog/Model/ResourceModel/Post/Collection.php
namespace MiVendor\Blog\Model\ResourceModel\Post;

use Magento\Framework\Model\ResourceModel\Db\Collection\AbstractCollection;
use MiVendor\Blog\Model\Post;
use MiVendor\Blog\Model\ResourceModel\Post as PostResource;

class Collection extends AbstractCollection
{
    protected function _construct(): void
    {
        // (ModelClass, ResourceModelClass)
        $this->_init(Post::class, PostResource::class);
    }

    // Scopes reutilizables
    public function addActiveFilter(): self
    {
        $this->addFieldToFilter('is_active', Post::STATUS_ENABLED);
        return $this;
    }

    public function addAuthorFilter(int $authorId): self
    {
        $this->addFieldToFilter('author_id', $authorId);
        return $this;
    }

    public function orderByNewest(): self
    {
        $this->setOrder('created_at', self::SORT_ORDER_DESC);
        return $this;
    }
}
```

## Cómo se usan juntas

```php
// Cargar un registro por ID (vía ResourceModel)
$post = $this->postFactory->create();
$this->postResource->load($post, 42);

if (!$post->getId()) {
    // No existe
}

// Guardar
$post->setTitle('Mi Post');
$this->postResource->save($post);

// Eliminar
$this->postResource->delete($post);

// Collection — múltiples registros
$collection = $this->postCollectionFactory->create();
$collection->addActiveFilter()
           ->addAuthorFilter(5)
           ->orderByNewest()
           ->setPageSize(10)
           ->setCurPage(1);

foreach ($collection as $post) {
    echo $post->getTitle();
}

// Contar sin cargar todos
$total = $collection->getSize();
```

## La Factory: cómo instanciar Models

```php
use MiVendor\Blog\Model\PostFactory;
use MiVendor\Blog\Model\ResourceModel\Post\CollectionFactory;

class AlgunServicio
{
    public function __construct(
        private readonly PostFactory $postFactory,
        private readonly CollectionFactory $postCollectionFactory,
        private readonly \MiVendor\Blog\Model\ResourceModel\Post $postResource
    ) {}

    public function crear(): void
    {
        // SIEMPRE usar Factory, nunca new Post()
        $post = $this->postFactory->create();
        $post->setTitle('Nuevo post');
        $this->postResource->save($post);
    }

    public function getActivos(): array
    {
        // SIEMPRE usar CollectionFactory
        $collection = $this->postCollectionFactory->create();
        $collection->addActiveFilter();
        return $collection->getItems();
    }
}
```

`PostFactory` y `CollectionFactory` son **auto-generadas** por Magento en `generated/`. No las creas tú.

## `getData()` vs getters explícitos

`AbstractModel` almacena todo en un array interno `$_data`. Puedes acceder de dos formas:

```php
// getData() — genérico, siempre funciona
$title = $post->getData('title');

// Getter explícito — más seguro, IDEs lo autocompletan
$title = $post->getTitle();

// Magic getter — AbstractModel genera __get/__set
// getTitleCase() → busca 'title_case' en $_data
// Por convención, SIEMPRE define getters/setters explícitos en tu Model
```

## AbstractModel: métodos útiles heredados

```php
// Identidad
$post->getId();                        // PK (post_id en nuestro caso)
$post->setId(42);

// Datos crudos
$post->getData();                      // Array completo
$post->getData('title');               // Un campo específico
$post->setData('title', 'Nuevo');
$post->setData(['title' => 'A', 'content' => 'B']); // Múltiples campos

// Estado
$post->isObjectNew();                  // true si no tiene ID guardado en DB
$post->hasDataChanges();               // true si algún dato cambió desde la carga
$post->getOrigData('title');           // valor antes de los cambios

// Serialización
$post->toArray();                      // Array de todos los datos
$post->toJson();                       // JSON
```

## AbstractCollection: condiciones disponibles

```php
// Igualdad (default)
->addFieldToFilter('campo', 'valor')
->addFieldToFilter('campo', ['eq' => 'valor'])

// Comparaciones
->addFieldToFilter('campo', ['neq' => 'valor'])     // !=
->addFieldToFilter('campo', ['gt'  => 10])          // >
->addFieldToFilter('campo', ['gteq'=> 10])          // >=
->addFieldToFilter('campo', ['lt'  => 100])         // <
->addFieldToFilter('campo', ['lteq'=> 100])         // <=

// Like
->addFieldToFilter('campo', ['like' => '%texto%'])
->addFieldToFilter('campo', ['nlike'=> '%texto%'])  // NOT LIKE

// IN
->addFieldToFilter('campo', ['in'   => [1, 2, 3]])
->addFieldToFilter('campo', ['nin'  => [1, 2, 3]])  // NOT IN

// NULL
->addFieldToFilter('campo', ['null'   => true])
->addFieldToFilter('campo', ['notnull'=> true])

// OR entre campos
->addFieldToFilter(
    ['title', 'content'],
    [['like' => '%php%'], ['like' => '%php%']]
)

// Orden y paginación
->setOrder('created_at', 'DESC')
->setPageSize(20)
->setCurPage(2)         // Página 2 (OFFSET = 20)
->getSize()             // COUNT(*) sin cargar datos
->getItems()            // Array de Models
->getFirstItem()        // Primer item o Model vacío
```

## Joins en Collection

```php
class Collection extends AbstractCollection
{
    public function joinWithAuthor(): self
    {
        $this->getSelect()->join(
            ['author' => $this->getTable('admin_user')],  // alias => tabla
            'main_table.author_id = author.user_id',
            ['author_name' => 'author.firstname']          // columnas a traer
        );
        return $this;
    }
}
```

## Cuándo usar Model directo vs Repository

```
Model / ResourceModel directo:
  ✅ Scripts de migración (Data Patches)
  ✅ Código interno del módulo
  ✅ Queries complejas con joins
  ❌ APIs públicas del módulo

Repository (módulo 8.5):
  ✅ APIs públicas de tu módulo
  ✅ Lo que otros módulos consumen
  ✅ Cuando necesitas caché de entidades
  ❌ Queries muy complejas con joins
```

---

## Resumen

```
Model           →  La entidad (datos, getters/setters, lógica de negocio)
ResourceModel   →  Acceso a DB (tabla, PK, queries específicas)
Collection      →  Queries de múltiples registros

Instanciación:
  PostFactory::create()           →  nuevo Model (auto-generada)
  CollectionFactory::create()     →  nueva Collection (auto-generada)
  NUNCA "new Post()" directamente
```

## Ejercicios

### Ejercicio 1 — Crear la trinidad para una entidad FAQ

Crea el Model, ResourceModel y Collection para una entidad `Question` con campos: `question_id`, `title`, `content`, `is_active`, `sort_order`, `created_at`.

<details>
<summary>Ver solución</summary>

```php
<?php
// Model/Question.php
namespace MiVendor\Faq\Model;

use Magento\Framework\Model\AbstractModel;

class Question extends AbstractModel
{
    public const STATUS_ENABLED  = 1;
    public const STATUS_DISABLED = 0;

    protected function _construct(): void
    {
        $this->_init(\MiVendor\Faq\Model\ResourceModel\Question::class);
    }

    public function getTitle(): string       { return (string) $this->getData('title'); }
    public function setTitle(string $v): self { return $this->setData('title', $v); }
    public function getContent(): string     { return (string) $this->getData('content'); }
    public function setContent(string $v): self { return $this->setData('content', $v); }
    public function isActive(): bool         { return (bool) $this->getData('is_active'); }
    public function setIsActive(bool $v): self { return $this->setData('is_active', (int) $v); }
    public function getSortOrder(): int      { return (int) $this->getData('sort_order'); }
    public function setSortOrder(int $v): self { return $this->setData('sort_order', $v); }
}
```

```php
<?php
// Model/ResourceModel/Question.php
namespace MiVendor\Faq\Model\ResourceModel;

use Magento\Framework\Model\ResourceModel\Db\AbstractDb;

class Question extends AbstractDb
{
    protected function _construct(): void
    {
        $this->_init('mivendor_faq_question', 'question_id');
    }
}
```

```php
<?php
// Model/ResourceModel/Question/Collection.php
namespace MiVendor\Faq\Model\ResourceModel\Question;

use Magento\Framework\Model\ResourceModel\Db\Collection\AbstractCollection;
use MiVendor\Faq\Model\Question;
use MiVendor\Faq\Model\ResourceModel\Question as QuestionResource;

class Collection extends AbstractCollection
{
    protected $_idFieldName = 'question_id';

    protected function _construct(): void
    {
        $this->_init(Question::class, QuestionResource::class);
    }

    public function addActiveFilter(): self
    {
        return $this->addFieldToFilter('is_active', Question::STATUS_ENABLED);
    }

    public function orderBySortOrder(): self
    {
        return $this->setOrder('sort_order', self::SORT_ORDER_ASC);
    }
}
```

**Nota clave**: `$_idFieldName = 'question_id'` — necesario cuando el PK no se llama `id`.

### Ejercicio 2 — Queries con Collection

Escribe un servicio que use la Collection de preguntas para:
1. Devolver las 5 preguntas activas más recientes
2. Contar el total sin cargarlas todas en memoria
3. Buscar por palabra clave en título O contenido

<details>
<summary>Ver solución</summary>

```php
<?php
namespace MiVendor\Faq\Model;

use MiVendor\Faq\Model\ResourceModel\Question\CollectionFactory;

class QuestionService
{
    public function __construct(
        private readonly CollectionFactory $collectionFactory
    ) {}

    public function getLatestActive(int $limit = 5): array
    {
        $collection = $this->collectionFactory->create();
        $collection->addActiveFilter()
                   ->setOrder('created_at', 'DESC')
                   ->setPageSize($limit)
                   ->setCurPage(1);
        return $collection->getItems();
    }

    public function countActive(): int
    {
        $collection = $this->collectionFactory->create();
        $collection->addActiveFilter();
        // getSize() → SELECT COUNT(*) — sin cargar datos
        return $collection->getSize();
    }

    public function search(string $keyword): array
    {
        $collection = $this->collectionFactory->create();
        $collection->addActiveFilter();

        // OR entre título y contenido
        $collection->addFieldToFilter(
            ['title', 'content'],
            [
                ['like' => '%' . $keyword . '%'],
                ['like' => '%' . $keyword . '%']
            ]
        );

        return $collection->getItems();
    }
}
```

**Por qué `getSize()` en vez de `count($collection->getItems())`**:
- `getSize()` → `SELECT COUNT(*)` — un número, nada en memoria
- `count(getItems())` → carga TODOS los registros — peligroso en tablas grandes

</details>
