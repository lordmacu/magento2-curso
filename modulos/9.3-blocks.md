## Qué es un Block

🔄 **Laravel**: No hay equivalente directo. Se parece a un View Composer (datos para el template) combinado con un componente Blade (encapsula lógica + template).

Un Block en Magento es una clase PHP que:
1. Provee datos al template (`.phtml`)
2. Puede tener caché propia
3. Puede tener blocks hijos
4. Es instanciado por el sistema de layout

```
Block (PHP)          →  lógica de presentación, acceso a datos
Template (.phtml)    →  HTML con PHP mínimo, usa los métodos del Block
```

El template llama a `$block->getXxx()` y el Block sabe cómo obtener esos datos.

## Block básico

```php
<?php
// app/code/MiVendor/Blog/Block/Post/View.php
namespace MiVendor\Blog\Block\Post;

use Magento\Framework\View\Element\Template;
use Magento\Framework\View\Element\Template\Context;
use MiVendor\Blog\Api\PostRepositoryInterface;
use Magento\Framework\Registry;

class View extends Template
{
    public function __construct(
        Context $context,
        private readonly PostRepositoryInterface $postRepository,
        private readonly Registry $registry,
        array $data = []
    ) {
        parent::__construct($context, $data);
    }

    public function getPost(): ?\MiVendor\Blog\Api\Data\PostInterface
    {
        return $this->registry->registry('current_post');
    }

    public function getPostTitle(): string
    {
        return $this->getPost()?->getTitle() ?? '';
    }

    public function getPostContent(): string
    {
        return $this->getPost()?->getContent() ?? '';
    }

    public function getReadMoreUrl(): string
    {
        $post = $this->getPost();
        if (!$post) {
            return '';
        }
        return $this->getUrl('blog/post/view', ['id' => $post->getPostId()]);
    }
}
```

**Nota sobre `Context`**: `Template\Context` inyecta decenas de servicios comunes (request, layout, cache, etc.) en un solo objeto. Es el patrón estándar — siempre es el primer argumento.

## Tipos de Block

### 1. `Template` — el más común

```php
use Magento\Framework\View\Element\Template;

class MiBlock extends Template
{
    // Para bloques con template .phtml
    protected $_template = 'MiVendor_Blog::post/view.phtml'; // template por defecto
}
```

### 2. `AbstractBlock` — sin template

```php
use Magento\Framework\View\Element\AbstractBlock;

class MiBlock extends AbstractBlock
{
    // Para bloques que generan HTML directamente en PHP
    protected function _toHtml(): string
    {
        return '<div class="mi-bloque">' . $this->escapeHtml($this->getData('text')) . '</div>';
    }
}
```

### 3. `Text` — solo texto

```php
// Para insertar texto/HTML estático desde el layout XML
use Magento\Framework\View\Element\Text;
// Ya implementado en el core — úsalo directamente en XML
```

### 4. Blocks del admin (UI Components)

```php
use Magento\Backend\Block\Template;
// Para blocks del área adminhtml
```

## El template asociado

```php
// Definir template en el layout XML (preferido):
// <block class="..." template="MiVendor_Blog::post/view.phtml"/>

// O en el Block (template por defecto):
class View extends Template
{
    protected $_template = 'MiVendor_Blog::post/view.phtml';
}
```

**Sintaxis del template**: `{VendorName}_{ModuleName}::{ruta/al/archivo.phtml}`

El archivo está en: `view/frontend/templates/ruta/al/archivo.phtml`

## Acceso a datos en el Block — vía `$data`

Los `<arguments>` del layout XML se inyectan como `$data`:

```xml
<!-- En el XML -->
<block class="MiVendor\Blog\Block\Post\View" name="blog.post.view" template="...">
    <arguments>
        <argument name="show_author" xsi:type="boolean">true</argument>
        <argument name="max_posts" xsi:type="number">5</argument>
        <argument name="title" xsi:type="string">Últimas entradas</argument>
    </arguments>
</block>
```

```php
// En el Block:
$showAuthor = $this->getData('show_author');  // true
$maxPosts   = (int) $this->getData('max_posts'); // 5
$title      = $this->getData('title'); // 'Últimas entradas'

// Acceso desde el template:
// $block->getData('show_author')
// o con getter mágico:
// $block->getShowAuthor()
// $block->getMaxPosts()
```

## Métodos útiles heredados de `Template`

```php
// URLs
$this->getUrl('blog/post/view', ['id' => 42]);   // URL completa
$this->getBaseUrl();                               // URL base del sitio
$this->getViewFileUrl('MiVendor_Blog::images/logo.svg'); // URL de asset estático

// Seguridad — SIEMPRE usar al outputear datos del usuario
$this->escapeHtml($string);        // para texto dentro de HTML
$this->escapeHtmlAttr($string);    // para atributos HTML
$this->escapeUrl($url);            // para URLs
$this->escapeJs($string);          // para strings dentro de JS

// Traducciones
$this->__('Texto a traducir');     // equivalente a __() global

// Layout y blocks hijos
$this->getChildHtml('block_alias');       // renderizar block hijo por alias
$this->getChildHtml();                    // renderizar todos los hijos
$this->getChildBlock('block_alias');      // obtener el objeto Block hijo

// Request
$this->getRequest()->getParam('id');

// Store
$this->_storeManager->getStore()->getId();
```

## Blocks hijos

```xml
<!-- En el layout XML -->
<block class="MiVendor\Blog\Block\Post\View" name="blog.post.view" template="...">
    <block class="MiVendor\Blog\Block\Post\Author"
           name="blog.post.author"
           as="author"                          <!-- alias para getChildHtml() -->
           template="MiVendor_Blog::post/author.phtml"/>
    <block class="MiVendor\Blog\Block\Post\Tags"
           name="blog.post.tags"
           as="tags"
           template="MiVendor_Blog::post/tags.phtml"/>
</block>
```

```php
// En el template del Block padre (post/view.phtml):
echo $block->getChildHtml('author');  // renderiza author.phtml
echo $block->getChildHtml('tags');    // renderiza tags.phtml
echo $block->getChildHtml();          // renderiza todos los hijos en orden
```

## Caché de Block

Magento puede cachear el HTML generado por un Block:

```php
class RecentPosts extends Template
{
    // Tiempo de vida en segundos (null = no cachear)
    protected $_cacheLifetime = 3600; // 1 hora

    // Etiquetas para invalidación selectiva
    protected $_cacheTags = ['mivendor_blog_post'];

    // Clave única para este block (diferencia por store, customer group, etc.)
    public function getCacheKey(): string
    {
        return 'mivendor_blog_recent_posts_' . $this->_storeManager->getStore()->getId();
    }

    // O más explícito:
    public function getCacheKeyInfo(): array
    {
        return [
            'MIVENDOR_BLOG_RECENT_POSTS',
            $this->_storeManager->getStore()->getId(),
            $this->getData('max_posts'),
        ];
    }
}
```

```xml
<!-- También configurable desde el XML -->
<block class="..." name="...">
    <arguments>
        <argument name="cache_lifetime" xsi:type="number">3600</argument>
        <argument name="cache_key" xsi:type="string">mi_block_unico</argument>
    </arguments>
</block>
```

## Ciclo de vida del Block

```
1. Instanciación (DI + $data del XML)
2. _construct()       ← inicialización interna
3. _prepareLayout()   ← configurar layout (agregar blocks hijos dinámicamente)
4. _beforeToHtml()    ← antes de renderizar
5. _toHtml()          ← renderización (Template carga el .phtml)
6. _afterToHtml()     ← post-proceso del HTML
```

```php
class RecentPosts extends Template
{
    protected function _prepareLayout(): self
    {
        // Agregar blocks hijos dinámicamente según lógica PHP
        if ($this->getData('show_pagination')) {
            $this->addChild(
                'pagination',
                \Magento\Theme\Block\Html\Pager::class,
                ['block_id' => 'blog.pager']
            );
        }

        return parent::_prepareLayout();
    }

    protected function _beforeToHtml(): self
    {
        // Preparar datos antes de renderizar
        $this->assign('posts', $this->getRecentPosts());
        return parent::_beforeToHtml();
    }
}
```

## Inyección vs Registry

```php
// ❌ Registry (legacy) — evitar en código nuevo
$post = $this->registry->registry('current_product');

// ✅ Inyectar el Repository y cargar desde el Request
class View extends Template
{
    public function __construct(
        Context $context,
        private readonly PostRepositoryInterface $postRepository,
        array $data = []
    ) {
        parent::__construct($context, $data);
    }

    public function getPost(): ?\MiVendor\Blog\Api\Data\PostInterface
    {
        $postId = (int) $this->getRequest()->getParam('id');
        try {
            return $this->postRepository->getById($postId);
        } catch (\Magento\Framework\Exception\NoSuchEntityException $e) {
            return null;
        }
    }
}
```

`Registry` sigue usándose en el core para pasar el producto/categoría actual al Block, pero en código nuevo preferimos inyección directa.

---

## Resumen

```
Block = clase PHP que provee datos al template .phtml

Tipos:
  Template      →  con archivo .phtml (el más común)
  AbstractBlock →  genera HTML directamente en _toHtml()

Constructor: Context (primer arg) + dependencias + array $data

Datos del XML → getData('campo') o getter mágico getData*()

Métodos clave:
  escapeHtml()       →  XSS prevention (obligatorio)
  getUrl()           →  generar URLs
  getChildHtml()     →  renderizar hijos
  getData()          →  argumentos del XML

Caché: $_cacheLifetime + getCacheKeyInfo()
```

## Ejercicios

### Ejercicio 1 — Block de posts recientes para el sidebar

Crea `MiVendor\Blog\Block\Sidebar\RecentPosts` que:
1. Lea `max_posts` de los argumentos del XML (default 5)
2. Use `PostRepositoryInterface` para obtener los posts activos más recientes
3. Tenga caché de 1 hora por store

<details>
<summary>Ver solución</summary>

```php
<?php
namespace MiVendor\Blog\Block\Sidebar;

use Magento\Framework\View\Element\Template;
use Magento\Framework\View\Element\Template\Context;
use MiVendor\Blog\Api\PostRepositoryInterface;
use Magento\Framework\Api\SearchCriteriaBuilder;
use Magento\Framework\Api\SortOrderBuilder;
use Magento\Framework\Api\SortOrder;

class RecentPosts extends Template
{
    protected $_template = 'MiVendor_Blog::sidebar/recent-posts.phtml';
    protected $_cacheLifetime = 3600;
    protected $_cacheTags = ['mivendor_blog_post'];

    public function __construct(
        Context $context,
        private readonly PostRepositoryInterface $postRepository,
        private readonly SearchCriteriaBuilder $searchCriteriaBuilder,
        private readonly SortOrderBuilder $sortOrderBuilder,
        array $data = []
    ) {
        parent::__construct($context, $data);
    }

    public function getCacheKeyInfo(): array
    {
        return [
            'MIVENDOR_BLOG_SIDEBAR_RECENT',
            $this->_storeManager->getStore()->getId(),
            $this->getMaxPosts(),
        ];
    }

    public function getMaxPosts(): int
    {
        return (int) ($this->getData('max_posts') ?: 5);
    }

    public function getRecentPosts(): array
    {
        $sortOrder = $this->sortOrderBuilder
            ->setField('created_at')
            ->setDirection(SortOrder::SORT_DESC)
            ->create();

        $searchCriteria = $this->searchCriteriaBuilder
            ->addFilter('is_active', 1)
            ->setSortOrders([$sortOrder])
            ->setPageSize($this->getMaxPosts())
            ->setCurrentPage(1)
            ->create();

        return $this->postRepository->getList($searchCriteria)->getItems();
    }
}
```

```xml
<!-- view/frontend/layout/default.xml -->
<referenceContainer name="sidebar.main">
    <block class="MiVendor\Blog\Block\Sidebar\RecentPosts"
           name="blog.sidebar.recent"
           template="MiVendor_Blog::sidebar/recent-posts.phtml">
        <arguments>
            <argument name="max_posts" xsi:type="number">5</argument>
        </arguments>
    </block>
</referenceContainer>
```

</details>

### Ejercicio 2 — Block con seguridad XSS

Dado este template incorrecto, identifica los problemas y corrígelos:

```php
<!-- INCORRECTO -->
<h1><?= $post->getTitle() ?></h1>
<div><?= $post->getContent() ?></div>
<a href="<?= $block->getUrl('blog/post/view', ['id' => $post->getPostId()]) ?>">
    Ver más
</a>
<script>
    var postId = <?= $post->getPostId() ?>;
</script>
```

<details>
<summary>Ver solución</summary>

```php
<!-- CORRECTO -->
<h1><?= $block->escapeHtml($post->getTitle()) ?></h1>

<!-- getContent() puede contener HTML válido (WYSIWYG) — usar escapeHtmlAttr solo para atributos -->
<!-- Para contenido HTML permitido, usar directamente (asumiendo que ya está sanitizado al guardar) -->
<div><?= /* @noEscape */ $post->getContent() ?></div>

<!-- URLs: escapeUrl() -->
<a href="<?= $block->escapeUrl($block->getUrl('blog/post/view', ['id' => $post->getPostId()])) ?>">
    Ver más
</a>

<!-- En JS: escapeJs() para valores dentro de strings JS -->
<script>
    var postId = <?= (int) $post->getPostId() ?>;  // cast a int es suficiente para números
    var postTitle = '<?= $block->escapeJs($post->getTitle()) ?>';
</script>
```

**Reglas de escape en Magento**:
| Contexto | Método |
|---|---|
| Texto en HTML | `escapeHtml()` |
| Atributos HTML | `escapeHtmlAttr()` |
| URLs (href, src) | `escapeUrl()` |
| Dentro de JS string | `escapeJs()` |
| Números | `(int)` o `(float)` cast |
| HTML ya sanitizado | `/* @noEscape */` (con comentario explícito) |

</details>
