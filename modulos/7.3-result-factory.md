# 7.3 — ResultFactory: Tipos de Respuesta

> **Objetivo**: Dominar los cinco tipos de respuesta que puede devolver un Controller en Magento — cuándo usar cada uno y cómo configurarlos correctamente.
> **Estado**: ⬜ Pendiente
> **Prerequisito**: [7.2 — Controllers: una clase por Action](7.2-controllers.md)

---

## Los cinco tipos de resultado

```
Page     → HTML completo con layout XML y templates
JSON     → respuesta JSON para AJAX
Redirect → redirección HTTP (301/302)
Forward  → reenvío interno sin HTTP redirect
Raw      → respuesta libre (texto, XML, CSV, binarios)
```

Todos viven en `Magento\Framework\Controller\Result\` y todos implementan `ResultInterface`.

---

## 1. Page — respuesta HTML

El más común. Renderiza el layout XML del módulo más los templates `.phtml`.

```php
use Magento\Framework\View\Result\PageFactory;

class Index implements HttpGetActionInterface
{
    public function __construct(
        private readonly PageFactory $pageFactory,
    ) {}

    public function execute(): \Magento\Framework\Controller\ResultInterface
    {
        $page = $this->pageFactory->create();

        // Configurar el <title> de la página
        $page->getConfig()->getTitle()->set(__('Lista de Posts'));

        // Agregar meta description
        $page->getConfig()->setDescription('Los últimos posts del blog');

        // Agregar un handle de layout extra (para cargar XML específico)
        $page->addHandle('mivendor_blog_post_list');

        // Cambiar el layout (1column, 2columns-left, etc.)
        $page->getConfig()->setPageLayout('1column');

        return $page;
    }
}
```

**Cuándo usarlo**: cualquier página que necesita renderizarse con el layout completo de Magento (header, footer, sidebar, etc.).

---

## 2. JSON — respuesta AJAX

```php
use Magento\Framework\Controller\Result\JsonFactory;

class GetPost implements HttpGetActionInterface
{
    public function __construct(
        private readonly JsonFactory             $jsonFactory,
        private readonly PostRepositoryInterface $postRepository,
        private readonly RequestInterface        $request,
    ) {}

    public function execute(): \Magento\Framework\Controller\ResultInterface
    {
        $result = $this->jsonFactory->create();

        try {
            $postId = (int) $this->request->getParam('id');
            $post   = $this->postRepository->getById($postId);

            $result->setData([
                'success' => true,
                'post'    => [
                    'id'      => $post->getId(),
                    'title'   => $post->getTitle(),
                    'content' => $post->getContent(),
                ],
            ]);

        } catch (\Exception $e) {
            $result->setHttpResponseCode(404);
            $result->setData([
                'success' => false,
                'message' => $e->getMessage(),
            ]);
        }

        return $result;
    }
}
```

```javascript
// Desde el frontend JavaScript:
fetch('/blog/post/getpost?id=5')
    .then(r => r.json())
    .then(data => {
        if (data.success) console.log(data.post.title);
    });
```

**Cuándo usarlo**: endpoints AJAX, APIs internas del módulo, respuestas a formularios asíncronos.

### Códigos HTTP en JSON

```php
$result->setHttpResponseCode(200); // OK (default)
$result->setHttpResponseCode(400); // Bad Request
$result->setHttpResponseCode(401); // Unauthorized
$result->setHttpResponseCode(404); // Not Found
$result->setHttpResponseCode(500); // Server Error
```

## 3. Redirect — redirección HTTP

```php
use Magento\Framework\Controller\Result\RedirectFactory;

class Save implements HttpPostActionInterface
{
    public function __construct(
        private readonly RedirectFactory  $redirectFactory,
        private readonly ManagerInterface $messageManager,
    ) {}

    public function execute(): \Magento\Framework\Controller\ResultInterface
    {
        $redirect = $this->redirectFactory->create();

        // Ruta interna de Magento
        $redirect->setPath('blog/post/index');

        // Con parámetros
        $redirect->setPath('blog/post/view', ['id' => 5, '_fragment' => 'comments']);

        // URL externa
        $redirect->setUrl('https://ejemplo.com');

        // Volver a la página anterior
        $redirect->setRefererUrl();

        // Código HTTP (default: 302)
        $redirect->setHttpResponseCode(301); // permanente

        return $redirect;
    }
}
```

### Redirect con mensaje flash

```php
// El patrón Post/Redirect/Get de Magento:
$this->messageManager->addSuccessMessage(__('Post guardado correctamente.'));
$this->messageManager->addErrorMessage(__('Error al procesar.'));
$this->messageManager->addWarningMessage(__('Atención: revisa los datos.'));
$this->messageManager->addNoticeMessage(__('Recuerda activar el post.'));

return $this->redirectFactory->create()->setPath('blog/post/index');
// → Los mensajes aparecen en la página destino automáticamente
```

**Cuándo usarlo**: después de procesar un formulario POST (patrón PRG — Post/Redirect/Get).

---

## 4. Forward — reenvío interno

No genera una redirección HTTP — Magento internamente ejecuta otro Controller sin que el browser lo sepa.

```php
use Magento\Framework\Controller\Result\ForwardFactory;

class View implements HttpGetActionInterface
{
    public function __construct(
        private readonly ForwardFactory          $forwardFactory,
        private readonly PostRepositoryInterface $postRepository,
        private readonly RequestInterface        $request,
    ) {}

    public function execute(): \Magento\Framework\Controller\ResultInterface
    {
        $postId = (int) $this->request->getParam('id');

        try {
            $this->postRepository->getById($postId);
        } catch (\Magento\Framework\Exception\NoSuchEntityException) {
            // Forward al 404 de Magento — la URL del browser NO cambia
            $forward = $this->forwardFactory->create();
            $forward->forward('noroute');
            return $forward;
        }

        return $this->pageFactory->create();
    }
}
```

```php
// Otras formas de Forward:
$forward->setController('index');  // cambiar el controller
$forward->setModule('cms');        // cambiar el módulo
$forward->setActionName('index');  // cambiar la acción
$forward->forward('noroute');      // shortcut para el 404
```

**Cuándo usarlo**:
- Mostrar 404 sin cambiar la URL del browser
- Delegar a otro controller internamente
- Diferente al Redirect: el usuario no ve el cambio de URL

## 5. Raw — respuesta libre

Máximo control sobre la respuesta HTTP.

```php
use Magento\Framework\Controller\Result\RawFactory;

class Export implements HttpGetActionInterface
{
    public function __construct(
        private readonly RawFactory $rawFactory,
    ) {}

    public function execute(): \Magento\Framework\Controller\ResultInterface
    {
        $result = $this->rawFactory->create();

        // CSV descargable
        $result->setHeader('Content-Type', 'text/csv');
        $result->setHeader('Content-Disposition', 'attachment; filename="posts.csv"');
        $result->setContents($this->generateCsv());

        return $result;
    }

    // XML
    public function executeXml(): \Magento\Framework\Controller\ResultInterface
    {
        $result = $this->rawFactory->create();
        $result->setHeader('Content-Type', 'application/xml');
        $result->setContents('<posts><post id="1"/></posts>');
        return $result;
    }

    // Texto plano para health checks
    public function executeHealth(): \Magento\Framework\Controller\ResultInterface
    {
        $result = $this->rawFactory->create();
        $result->setHeader('Content-Type', 'text/plain');
        $result->setContents('OK');
        return $result;
    }
}
```

**Cuándo usarlo**: exportaciones (CSV, Excel, XML), health checks, webhooks, respuestas binarias.

## Tabla de decisión

| Necesitas | Usa |
|---|---|
| Página HTML con layout completo | `PageFactory` |
| Respuesta JSON para AJAX | `JsonFactory` |
| Redirigir al usuario a otra URL | `RedirectFactory` |
| Mostrar 404 sin cambiar URL | `ForwardFactory` → `noroute` |
| CSV, XML, texto plano, binario | `RawFactory` |

---

## Inyectar las factories

```php
// Constructor con todas las factories (raramente necesitas todas)
public function __construct(
    private readonly \Magento\Framework\View\Result\PageFactory            $pageFactory,
    private readonly \Magento\Framework\Controller\Result\JsonFactory      $jsonFactory,
    private readonly \Magento\Framework\Controller\Result\RedirectFactory  $redirectFactory,
    private readonly \Magento\Framework\Controller\Result\ForwardFactory   $forwardFactory,
    private readonly \Magento\Framework\Controller\Result\RawFactory       $rawFactory,
) {}
```

---

## Resumen

```
PageFactory     → HTML con layout XML (el más común para páginas)
JsonFactory     → AJAX y APIs internas
RedirectFactory → después de POST, cambios de URL
ForwardFactory  → 404 interno, delegación sin redirect HTTP
RawFactory      → CSV, XML, binarios, health checks

Todas devuelven ResultInterface — el Controller siempre hace return $result
```

## Ejercicios

### Ejercicio 1 — Elegir el resultado correcto

Para cada escenario indica qué tipo de resultado usar:

```
A. Un endpoint /blog/post/status que devuelve el estado de un post en JSON.

B. Después de que un usuario envía el formulario de contacto del blog,
   mostrarle un mensaje de éxito y llevarlo de vuelta al formulario.

C. Una página /blog/author/profile que muestra el perfil del autor
   con sidebar, header y footer de la tienda.

D. Un endpoint /blog/export/csv que descarga todos los posts en CSV.

E. Un Controller que detecta que el ID solicitado no existe
   y debe mostrar el 404 de Magento sin cambiar la URL.
```

<details>
<summary>Ver solución</summary>

```
A. JsonFactory
   El cliente espera JSON — usar Page aquí sería un error.
   $result->setData(['id' => $id, 'status' => $post->getStatus()]);

B. RedirectFactory + MessageManager
   Patrón PRG (Post/Redirect/Get):
   $this->messageManager->addSuccessMessage(__('Mensaje enviado.'));
   return $this->redirectFactory->create()->setPath('blog/contact');

C. PageFactory
   Necesita el layout completo con todos los bloques de la tienda.
   $page = $this->pageFactory->create();
   $page->getConfig()->getTitle()->set($author->getName());
   return $page;

D. RawFactory
   CSV es una respuesta binaria/texto que requiere headers específicos.
   $result->setHeader('Content-Type', 'text/csv');
   $result->setHeader('Content-Disposition', 'attachment; filename="posts.csv"');

E. ForwardFactory → noroute
   forward('noroute') muestra el 404 de Magento sin redirect HTTP.
   La URL del browser permanece igual (/blog/post/view/id/999).
```

</details>

### Ejercicio 2 — Controller dual: HTML y JSON según el request

Crea un Controller `/blog/post/view` que devuelva:
- Una `Page` si es una request normal del browser
- Un `JSON` con los datos del post si el header `Accept: application/json` está presente (request AJAX)

<details>
<summary>Ver solución</summary>

```php
<?php
// Controller/Post/View.php
namespace MiVendor\Blog\Controller\Post;

use Magento\Framework\App\Action\HttpGetActionInterface;
use Magento\Framework\App\RequestInterface;
use Magento\Framework\View\Result\PageFactory;
use Magento\Framework\Controller\Result\JsonFactory;
use Magento\Framework\Controller\Result\ForwardFactory;
use Magento\Framework\Exception\NoSuchEntityException;
use MiVendor\Blog\Api\PostRepositoryInterface;

class View implements HttpGetActionInterface
{
    public function __construct(
        private readonly RequestInterface        $request,
        private readonly PageFactory             $pageFactory,
        private readonly JsonFactory             $jsonFactory,
        private readonly ForwardFactory          $forwardFactory,
        private readonly PostRepositoryInterface $postRepository,
    ) {}

    public function execute(): \Magento\Framework\Controller\ResultInterface
    {
        $postId = (int) $this->request->getParam('id');

        try {
            $post = $this->postRepository->getById($postId);
        } catch (NoSuchEntityException) {
            // JSON o Forward según el tipo de request
            if ($this->isJsonRequest()) {
                $result = $this->jsonFactory->create();
                $result->setHttpResponseCode(404);
                return $result->setData(['error' => 'Post not found']);
            }
            return $this->forwardFactory->create()->forward('noroute');
        }

        // Request AJAX/API → JSON
        if ($this->isJsonRequest()) {
            return $this->jsonFactory->create()->setData([
                'id'      => $post->getId(),
                'title'   => $post->getTitle(),
                'content' => $post->getContent(),
            ]);
        }

        // Request browser normal → Page
        $page = $this->pageFactory->create();
        $page->getConfig()->getTitle()->set($post->getTitle());
        return $page;
    }

    private function isJsonRequest(): bool
    {
        $accept = $this->request->getHeader('Accept') ?? '';
        return str_contains($accept, 'application/json')
            || $this->request->isAjax();
    }
}
```

```bash
# Request normal → HTML
curl http://localhost:8181/blog/post/view/id/1

# Request AJAX/JSON
curl -H "Accept: application/json" http://localhost:8181/blog/post/view/id/1
# → {"id":1,"title":"Mi Post","content":"..."}
```

</details>
