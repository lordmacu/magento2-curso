# 7.2 — Controllers: Una Clase por Action

> **Objetivo**: Entender por qué Magento usa una clase PHP por cada acción del controller, cómo estructurarlas correctamente y los patrones más comunes del frontend y el admin.
> **Estado**: ⬜ Pendiente
> **Prerequisito**: [7.1 — Request Routing: routes.xml y Front Controllers](7.1-routing.md)

---

## Por qué una clase por acción

🔄 **Laravel**: un Controller tiene múltiples métodos (`index`, `show`, `store`...).

```php
// Laravel — un controller, muchos métodos
class PostController extends Controller
{
    public function index() { ... }
    public function show($id) { ... }
    public function store(Request $request) { ... }
}
```

**Magento**: cada acción es una clase PHP independiente.

```
Controller/Post/Index.php  → execute() para /blog/post/index
Controller/Post/View.php   → execute() para /blog/post/view
Controller/Post/Save.php   → execute() para /blog/post/save
```

**Por qué**: cada clase tiene sus propias dependencias inyectadas — solo las que necesita. No hay un controller "gordo" con 10 dependencias de las cuales solo usa 2 por request.

## Anatomía de un Controller completo

```php
<?php
// app/code/MiVendor/Blog/Controller/Post/View.php
namespace MiVendor\Blog\Controller\Post;

use Magento\Framework\App\Action\HttpGetActionInterface;
use Magento\Framework\App\RequestInterface;
use Magento\Framework\View\Result\PageFactory;
use Magento\Framework\Exception\NoSuchEntityException;
use Magento\Framework\Controller\Result\RedirectFactory;
use MiVendor\Blog\Api\PostRepositoryInterface;

class View implements HttpGetActionInterface
{
    public function __construct(
        private readonly RequestInterface       $request,
        private readonly PageFactory            $pageFactory,
        private readonly RedirectFactory        $redirectFactory,
        private readonly PostRepositoryInterface $postRepository,
    ) {}

    public function execute(): \Magento\Framework\Controller\ResultInterface
    {
        $postId = (int) $this->request->getParam('id');

        if (!$postId) {
            return $this->redirectFactory->create()
                ->setPath('blog');
        }

        try {
            $post = $this->postRepository->getById($postId);
        } catch (NoSuchEntityException $e) {
            return $this->redirectFactory->create()
                ->setPath('noroute');
        }

        $page = $this->pageFactory->create();
        $page->getConfig()->getTitle()->set($post->getTitle());

        return $page;
    }
}
```

## Tipos de resultado que puede devolver execute()

```php
// 1. Página HTML (renderiza layout XML + templates)
return $this->pageFactory->create();

// 2. JSON (para AJAX)
$json = $this->resultJsonFactory->create();
$json->setData(['success' => true, 'message' => 'OK']);
return $json;

// 3. Redirect
$redirect = $this->redirectFactory->create();
$redirect->setPath('blog/post/index');         // ruta interna
$redirect->setUrl('https://ejemplo.com');      // URL externa
return $redirect;

// 4. Forward (reenvío interno sin redirect HTTP)
$forward = $this->resultForwardFactory->create();
$forward->forward('noroute');   // muestra el 404 de Magento
return $forward;

// 5. Raw (texto plano, HTML directo, XML)
$raw = $this->resultRawFactory->create();
$raw->setHeader('Content-Type', 'text/plain');
$raw->setContents('Respuesta en texto plano');
return $raw;
```

Más detalle en [7.3 — ResultFactory](7.3-result-factory.md).

```php
<?php
// Controller/Post/Index.php — lista todos los posts
namespace MiVendor\Blog\Controller\Post;

use Magento\Framework\View\Result\PageFactory;

class Index implements HttpGetActionInterface
{
    public function __construct(
        private readonly PageFactory $pageFactory,

    {
```

## Controller de formulario POST

```php
<?php
// Controller/Post/Save.php — procesa el formulario de creación
namespace MiVendor\Blog\Controller\Post;

use Magento\Framework\App\Action\HttpPostActionInterface;
use Magento\Framework\App\RequestInterface;
use Magento\Framework\Controller\Result\RedirectFactory;
use Magento\Framework\Message\ManagerInterface;
use MiVendor\Blog\Api\PostRepositoryInterface;
use MiVendor\Blog\Api\Data\PostInterfaceFactory;

class Save implements HttpPostActionInterface
{
    public function __construct(
        private readonly RequestInterface        $request,
        private readonly RedirectFactory         $redirectFactory,
        private readonly ManagerInterface        $messageManager,
        private readonly PostRepositoryInterface $postRepository,
        private readonly PostInterfaceFactory    $postFactory,
    ) {}

    public function execute(): \Magento\Framework\Controller\ResultInterface
    {
        $redirect = $this->redirectFactory->create();

        try {
            $post = $this->postFactory->create();
            $post->setTitle($this->request->getParam('title'));
            $post->setContent($this->request->getParam('content'));
            $post->setStatus('draft');

            $this->postRepository->save($post);

            $this->messageManager->addSuccessMessage(__('Post guardado correctamente.'));
            $redirect->setPath('blog/post/view', ['id' => $post->getId()]);

        } catch (\Exception $e) {
            $this->messageManager->addErrorMessage(__('Error al guardar: %1', $e->getMessage()));
            $redirect->setPath('blog/post/create');
        }

        return $redirect;
    }
}
```

## Controller AJAX (respuesta JSON)

```php
<?php
// Controller/Post/Delete.php — elimina por AJAX
namespace MiVendor\Blog\Controller\Post;

use Magento\Framework\App\Action\HttpPostActionInterface;
use Magento\Framework\App\RequestInterface;
use Magento\Framework\Controller\Result\JsonFactory;
use MiVendor\Blog\Api\PostRepositoryInterface;

class Delete implements HttpPostActionInterface
{
    public function __construct(
        private readonly RequestInterface        $request,
        private readonly JsonFactory             $jsonFactory,
        private readonly PostRepositoryInterface $postRepository,
    ) {}

    public function execute(): \Magento\Framework\Controller\ResultInterface
    {
        $result = $this->jsonFactory->create();

        try {
            $postId = (int) $this->request->getParam('id');
            $post   = $this->postRepository->getById($postId);
            $this->postRepository->delete($post);

            $result->setData(['success' => true]);

        } catch (\Exception $e) {
            $result->setData([
                'success' => false,
                'message' => $e->getMessage(),
            ]);
        }

        return $result;
    }
}
```

## Compartir lógica entre Controllers — AbstractController

Cuando varios Controllers del mismo módulo comparten lógica (autenticación, verificar parámetros...), usa una clase abstracta:

```php
<?php
// Controller/Post/AbstractPost.php
namespace MiVendor\Blog\Controller\Post;

use Magento\Framework\App\RequestInterface;
use Magento\Framework\Controller\Result\RedirectFactory;
use Magento\Framework\Exception\NoSuchEntityException;
use MiVendor\Blog\Api\PostRepositoryInterface;

abstract class AbstractPost
{
    public function __construct(
        protected readonly RequestInterface        $request,
        protected readonly RedirectFactory         $redirectFactory,
        protected readonly PostRepositoryInterface $postRepository,
    ) {}

    protected function initPost(): ?\MiVendor\Blog\Api\Data\PostInterface
    {
        $postId = (int) $this->request->getParam('id');

        if (!$postId) {
            return null;
        }

        try {
            return $this->postRepository->getById($postId);
        } catch (NoSuchEntityException) {
            return null;
        }
    }
}
```

```php
// Controller/Post/View.php — usa la clase abstracta
class View extends AbstractPost implements HttpGetActionInterface
{
    public function __construct(
        RequestInterface        $request,
        RedirectFactory         $redirectFactory,
        PostRepositoryInterface $postRepository,
        private readonly PageFactory $pageFactory,
    ) {
        parent::__construct($request, $redirectFactory, $postRepository);
    }

    public function execute(): \Magento\Framework\Controller\ResultInterface
    {
        $post = $this->initPost();

        if (!$post) {
            return $this->redirectFactory->create()->setPath('noroute');
        }

        return $this->pageFactory->create();
    }
}
```

## Acceder a parámetros del request

```php
// GET /blog/post/view?id=5&tab=comments
$id  = $this->request->getParam('id');           // "5" (string)
$id  = (int) $this->request->getParam('id');     // 5 (int)
$tab = $this->request->getParam('tab', 'info');  // "comments" (default: "info")

// POST body
$title   = $this->request->getPost('title');
$content = $this->request->getPost('content');

// Todos los params (GET + POST)
$params = $this->request->getParams();

// Verificar el método HTTP
$isPost = $this->request->isPost();
$isAjax = $this->request->isAjax();
```

## Convenciones de nomenclatura

```
URL               Controller class             Archivo
/blog/            Post\Index                   Controller/Post/Index.php
/blog/post/view   Post\View                    Controller/Post/View.php
/blog/post/save   Post\Save                    Controller/Post/Save.php
/blog/post/delete Post\Delete                  Controller/Post/Delete.php
/blog/post/create Post\Create                  Controller/Post/Create.php

Palabras reservadas PHP → sufijo "Action":
/blog/category/list  → Category\ListAction    Controller/Category/ListAction.php
```

---

## Resumen

```
Un Controller en Magento:
  - Es una clase PHP que implementa HttpGet/PostActionInterface
  - Tiene un solo método: execute()
  - Devuelve un ResultInterface (Page, JSON, Redirect, Raw, Forward)
  - Recibe sus dependencias vía DI en el constructor

Estructura de archivos:
  Controller/{Carpeta}/{Accion}.php
       │          │         └─ tercer segmento de la URL
       │          └─ segundo segmento de la URL
       └─ siempre "Controller/"

Para compartir lógica entre Controllers:
  → AbstractController con métodos protected compartidos
```


### Ejercicio 2 — Identificar el error en este Controller

Encuentra todos los problemas en este código y corrígelos:

```php
namespace MiVendor\Blog\Controller\Post;

class Save
{
    public function __construct(
        private readonly \Magento\Framework\App\RequestInterface $request,
        private readonly \Magento\Framework\View\Result\PageFactory $pageFactory,
    ) {}

    public function execute()
    {
        $title = $this->request->getParam('title');
        echo "Guardando: " . $title;

        $page = $this->pageFactory->create();
        return $page;
    }
}
```

<details>
<summary>Ver solución</summary>

**Problema 1**: No implementa ninguna `Http*ActionInterface`.
```php
// Sin interfaz, Magento no sabe qué método HTTP acepta
// → puede responder a GET y POST indistintamente
// Corrección:
class Save implements \Magento\Framework\App\Action\HttpPostActionInterface
```

**Problema 2**: Usa `echo` directamente.
```php
// echo en un Controller rompe el flujo de respuesta de Magento
// (los headers ya pueden haberse enviado, el layout se corrompe)
// Corrección: NUNCA usar echo/print/var_dump en Controllers
// → loguear con $this->logger->debug() o devolver JSON con el mensaje
```

**Problema 3**: Una acción `Save` (POST) devuelve una `Page`.
```php
// Semánticamente incorrecto — Save debería guardar y redirigir
// Corrección: devolver un Redirect después de guardar
$redirect = $this->redirectFactory->create();
$redirect->setPath('blog/post/index');
return $redirect;
```

**Versión corregida**:
```php
namespace MiVendor\Blog\Controller\Post;

use Magento\Framework\App\Action\HttpPostActionInterface;
use Magento\Framework\App\RequestInterface;
use Magento\Framework\Controller\Result\RedirectFactory;
use Magento\Framework\Message\ManagerInterface;

{
    public function __construct(
        private readonly RequestInterface  $request,
        private readonly RedirectFactory   $redirectFactory,
        private readonly ManagerInterface  $messageManager,
    ) {}

    public function execute(): \Magento\Framework\Controller\ResultInterface
    {
        $title = $this->request->getPost('title');

        // ... lógica de guardado ...

        $this->messageManager->addSuccessMessage(__('Post guardado.'));
        return $this->redirectFactory->create()->setPath('blog/post/index');
    }
}
```
