# 7.5 — Seguridad en Controllers: Form Keys y CSRF

> **Objetivo**: Entender cómo Magento protege los endpoints contra CSRF, cómo implementar Form Keys en formularios propios y cómo validar la autenticidad de las requests en Controllers del frontend.
> **Estado**: ⬜ Pendiente
> **Prerequisito**: [7.4 — Request Object: parámetros, headers y validación](7.4-request.md)

---

## El problema: CSRF en formularios web

CSRF (Cross-Site Request Forgery) ocurre cuando un sitio malicioso envía una request en nombre de un usuario autenticado sin que lo sepa.

```
1. Usuario logueado en tu tienda Magento
2. Usuario visita sitio malicioso
3. El sitio malicioso envía POST a /blog/post/delete?id=5
4. Magento lo procesa → el post se borra sin que el usuario lo quisiera
```

🔄 **Laravel**: usa `@csrf` en los formularios Blade y el middleware `VerifyCsrfToken`.

**Magento**: usa **Form Keys** — un token único por sesión que se incluye en cada formulario.

## Form Key en el frontend

### Agregar el Form Key a un formulario

```html
<!-- En tu template .phtml -->
<form action="<?= $block->getUrl('blog/post/save') ?>" method="post">

    <!-- OBLIGATORIO: Form Key de Magento -->
    <?= $block->getBlockHtml('formkey') ?>
    <!-- Genera: <input type="hidden" name="form_key" value="abc123xyz"> -->

    <input type="text" name="title" placeholder="Título">
    <textarea name="content"></textarea>
    <button type="submit">Guardar</button>
</form>
```

### Validar el Form Key en el Controller

```php
<?php
// Controller/Post/Save.php
namespace MiVendor\Blog\Controller\Post;

use Magento\Framework\App\Action\HttpPostActionInterface;
use Magento\Framework\App\RequestInterface;
use Magento\Framework\Data\Form\FormKey\Validator as FormKeyValidator;
use Magento\Framework\Controller\Result\RedirectFactory;
use Magento\Framework\Message\ManagerInterface;

class Save implements HttpPostActionInterface
{
    public function __construct(
        private readonly RequestInterface  $request,
        private readonly FormKeyValidator  $formKeyValidator,
        private readonly RedirectFactory   $redirectFactory,
        private readonly ManagerInterface  $messageManager,
    ) {}

    public function execute(): \Magento\Framework\Controller\ResultInterface
    {
        // Validar Form Key ANTES de procesar cualquier dato
        if (!$this->formKeyValidator->validate($this->request)) {
            $this->messageManager->addErrorMessage(__('Solicitud inválida.'));
            return $this->redirectFactory->create()->setPath('blog');
        }

        // A partir de aquí, la request es legítima
        $title   = $this->request->getPost('title');
        $content = $this->request->getPost('content');

        // ... procesar ...

        $this->messageManager->addSuccessMessage(__('Post guardado.'));
        return $this->redirectFactory->create()->setPath('blog/post/index');
    }
}
```

## Form Key en AJAX

```javascript
// Obtener el Form Key desde el cookie de Magento (siempre presente):
function getFormKey() {
    const cookies = document.cookie.split(';');
    for (const cookie of cookies) {
        const [key, value] = cookie.trim().split('=');
        if (key === 'form_key') return decodeURIComponent(value);
    }
    return '';
}

// Incluirlo en requests AJAX:
fetch('/blog/post/delete', {
    method: 'POST',
    headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
    body: `id=5&form_key=${getFormKey()}`,
});

// O con FormData:
const formData = new FormData();
formData.append('id', 5);
formData.append('form_key', getFormKey());
fetch('/blog/post/delete', { method: 'POST', body: formData });
```

## CsrfAwareActionInterface — control manual del CSRF

Para Controllers que necesitan omitir la validación de CSRF (webhooks externos, APIs propias):

```php
<?php
// Controller/Webhook/Receive.php
namespace MiVendor\Blog\Controller\Webhook;

use Magento\Framework\App\Action\HttpPostActionInterface;
use Magento\Framework\App\CsrfAwareActionInterface;
use Magento\Framework\App\Request\InvalidRequestException;
use Magento\Framework\App\RequestInterface;
use Magento\Framework\Controller\Result\JsonFactory;

class Receive implements HttpPostActionInterface, CsrfAwareActionInterface
{
    public function __construct(
        private readonly RequestInterface $request,
        private readonly JsonFactory      $jsonFactory,
    ) {}

    /**
     * Magento llama a esto antes de execute() — si lanza InvalidRequestException
     * se rechaza la request. Si no valida nada (return null), la deja pasar.
     */
    public function validateForCsrf(RequestInterface $request): ?bool
    {
        // Validación custom: verificar HMAC signature del webhook
        $signature = $request->getHeader('X-Webhook-Signature');
        $body      = $request->getContent();
        $secret    = 'mi-secreto-del-webhook';

        $expected = hash_hmac('sha256', $body, $secret);

        return hash_equals($expected, $signature ?? '');
        // true  → request válida, continúa
        // false → lanza InvalidRequestException automáticamente
        // null  → skip validación (úsalo con cuidado)
    }

    public function createCsrfValidationException(
        RequestInterface $request
    ): ?InvalidRequestException {
        // Opcional: personalizar la excepción/respuesta de error CSRF
        return null; // usa el comportamiento default de Magento
    }

    public function execute(): \Magento\Framework\Controller\ResultInterface
    {
        $data = json_decode($this->request->getContent(), true);
        // procesar webhook...
        return $this->jsonFactory->create()->setData(['received' => true]);
    }
}
```

## Validar que el usuario está logueado

```php
use Magento\Customer\Model\Session as CustomerSession;

class Create implements HttpGetActionInterface
{
    public function __construct(
        private readonly CustomerSession $customerSession,
        private readonly PageFactory     $pageFactory,
        private readonly RedirectFactory $redirectFactory,
    ) {}

    public function execute(): \Magento\Framework\Controller\ResultInterface
    {
        // Redirigir a login si no está autenticado
        if (!$this->customerSession->isLoggedIn()) {
            return $this->redirectFactory->create()
                ->setPath('customer/account/login');
        }

        // Usuario autenticado — obtener sus datos
        $customer   = $this->customerSession->getCustomer();
        $customerId = $this->customerSession->getCustomerId();
        $email      = $customer->getEmail();

        return $this->pageFactory->create();
    }
}
```

## Resumen de capas de seguridad

```
1. HttpPostActionInterface   → solo acepta POST (GET devuelve 404 automático)

2. FormKeyValidator          → verifica que el token CSRF es válido
   $this->formKeyValidator->validate($this->request)

3. Autenticación             → verificar que el usuario está logueado
   $this->customerSession->isLoggedIn()

4. Autorización              → verificar que puede hacer esta acción
   (permisos, propietario del recurso, etc.)

5. Validación de inputs      → sanitizar y validar todos los parámetros
   (int), (float), StripTags, validaciones de negocio

Orden de verificación en un Controller seguro:
  1. ¿Método HTTP correcto?     (HttpPostActionInterface lo hace solo)
  2. ¿Form Key válido?          (FormKeyValidator)
  3. ¿Usuario autenticado?      (CustomerSession::isLoggedIn)
  4. ¿Tiene permisos?           (lógica de negocio)
  5. ¿Inputs válidos?           (validación y sanitización)
  6. Procesar
```

## Ejercicios

### Ejercicio 1 — Controller POST seguro completo

Crea el Controller `POST /blog/comment/save` que:
1. Valida el Form Key
2. Verifica que el usuario está logueado
3. Valida que `post_id` sea entero positivo y `content` tenga al menos 10 caracteres
4. Si todo OK → redirige al post con mensaje de éxito

<details>
<summary>Ver solución</summary>

```php
<?php
// Controller/Comment/Save.php
namespace MiVendor\Blog\Controller\Comment;

use Magento\Framework\App\Action\HttpPostActionInterface;
use Magento\Framework\App\RequestInterface;
use Magento\Framework\Data\Form\FormKey\Validator as FormKeyValidator;
use Magento\Framework\Controller\Result\RedirectFactory;
use Magento\Framework\Message\ManagerInterface;
use Magento\Framework\Filter\StripTags;
use Magento\Customer\Model\Session as CustomerSession;

class Save implements HttpPostActionInterface
{
    public function __construct(
        private readonly RequestInterface  $request,
        private readonly FormKeyValidator  $formKeyValidator,
        private readonly RedirectFactory   $redirectFactory,
        private readonly ManagerInterface  $messageManager,
        private readonly CustomerSession   $customerSession,
        private readonly StripTags         $stripTags,
    ) {}

    public function execute(): \Magento\Framework\Controller\ResultInterface
    {
        $redirect = $this->redirectFactory->create();

        // 1. Validar Form Key (CSRF)
        if (!$this->formKeyValidator->validate($this->request)) {
            $this->messageManager->addErrorMessage(__('Solicitud inválida.'));
            return $redirect->setPath('blog');
        }

        // 2. Verificar autenticación
        if (!$this->customerSession->isLoggedIn()) {
            $this->messageManager->addErrorMessage(__('Debes iniciar sesión para comentar.'));
            return $redirect->setPath('customer/account/login');
        }

        // 3. Leer y validar inputs
        $postId  = (int) $this->request->getPost('post_id');
        $content = $this->stripTags->filter(
            trim($this->request->getPost('content', ''))
        );

        $errors = [];
        if ($postId <= 0) {
            $errors[] = __('Post inválido.');
        }
        if (strlen($content) < 10) {
            $errors[] = __('El comentario debe tener al menos 10 caracteres.');
        }

        if (!empty($errors)) {
            foreach ($errors as $error) {
                $this->messageManager->addErrorMessage($error);
            }
            return $redirect->setPath('blog/post/view', ['id' => $postId]);
        }

        // 4. Guardar comentario
        // $this->commentRepository->save(...)

        $this->messageManager->addSuccessMessage(__('Comentario publicado.'));
        return $redirect->setPath('blog/post/view', ['id' => $postId]);
    }
}
```

### Ejercicio 2 — Webhook sin CSRF con validación HMAC

Crea un Controller `POST /blog/webhook/github` que:
1. Omite la validación CSRF de Magento
2. Valida la firma HMAC del header `X-Hub-Signature-256`
3. Si la firma es válida → procesa el payload y devuelve JSON `{"ok": true}`
4. Si la firma es inválida → devuelve 401

<details>
<summary>Ver solución</summary>

```php
<?php
// Controller/Webhook/Github.php
namespace MiVendor\Blog\Controller\Webhook;

use Magento\Framework\App\Action\HttpPostActionInterface;
use Magento\Framework\App\CsrfAwareActionInterface;
use Magento\Framework\App\Request\InvalidRequestException;
use Magento\Framework\App\RequestInterface;
use Magento\Framework\Controller\Result\JsonFactory;

class Github implements HttpPostActionInterface, CsrfAwareActionInterface
{
    private const WEBHOOK_SECRET = 'mi-github-webhook-secret';

    public function __construct(
        private readonly RequestInterface $request,
        private readonly JsonFactory      $jsonFactory,
    ) {}

    public function validateForCsrf(RequestInterface $request): ?bool
    {
        $signature = $request->getHeader('X-Hub-Signature-256') ?? '';
        $body      = $request->getContent();

        if (empty($signature)) {
            return false;
        }

        // GitHub envía: sha256=<hash>
        $expected = 'sha256=' . hash_hmac('sha256', $body, self::WEBHOOK_SECRET);

        return hash_equals($expected, $signature);
    }

    public function createCsrfValidationException(
        RequestInterface $request
    ): ?InvalidRequestException {
        return null; // Magento manejará el error con su comportamiento default
    }

    public function execute(): \Magento\Framework\Controller\ResultInterface
    {
        $result = $this->jsonFactory->create();

        $payload = json_decode($this->request->getContent(), true);
        $event   = $this->request->getHeader('X-GitHub-Event');

        // Procesar según el tipo de evento
        if ($event === 'push') {
            // lógica para push events
        }

        return $result->setData(['ok' => true, 'event' => $event]);
    }
}
```

```xml
<!-- etc/frontend/routes.xml — ya declarado para el módulo Blog -->
<!-- La URL /blog/webhook/github se mapea automáticamente -->
```

```bash
# Probar con curl simulando GitHub:
SECRET="mi-github-webhook-secret"
BODY='{"ref":"refs/heads/main"}'
SIG="sha256=$(echo -n "$BODY" | openssl dgst -sha256 -hmac "$SECRET" | cut -d' ' -f2)"

curl -X POST http://localhost:8181/blog/webhook/github \
  -H "Content-Type: application/json" \
  -H "X-GitHub-Event: push" \
  -H "X-Hub-Signature-256: $SIG" \
  -d "$BODY"
# → {"ok":true,"event":"push"}
```
